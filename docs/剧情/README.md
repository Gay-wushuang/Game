## 使用边界

- 本目录决定世界观、人物经历、性格、称呼、对白语气、概念造型和剧情演出。
- 英雄基础数值、技能、升星、职业克制和战斗结算以 `docs/英雄类型/`、`docs/游戏规则/`、正式资源与 C# 运行时为准。
- 剧情中的卡名、卡组数量、奖励、价格和伤害数字是演出草案；进入制作前必须通过当前主数据校验。
- 高精度人设细节服务于概念图与宣传立绘。战斗像素立绘仍须遵守 `128×160 px` 画布、`112×144 px` 主体安全区和统一脚底基线。
