# 卡牌语义验收矩阵（V1 · 30 张）

本矩阵是 **Card Semantic Validation Phase** 的验收规格：记录每张锦囊的设计语义、运行时入口与当前实现状态。  
「必须 30 张」属于 **V1 测试规格**（见 `CardCatalog.V1ExpectedCount` 与 `TrainingArenaSmoke`），不属于运行时业务规则（`CardCatalog.ValidateRuntime` 只校验非空、ID 唯一、Lua 存在）。

## 实现状态图例

| 状态 | 含义 |
|------|------|
| **ATOMIC** | Lua 直接调用 `CardApi` 原子函数，组合逻辑在脚本层 |
| **HANDLER** | Lua 仅 `resolve_card_effect(handler)`，逻辑仍在 C# switch |
| **SEMANTIC_OK** | 已通过 `CardSemanticValidator` 或等效行为断言 |
| **PARTIAL** | 核心效果有，但表现/边界未完整（见备注） |
| **UNVERIFIED** | 能加载、能跑 Lua，尚无行为断言 |
