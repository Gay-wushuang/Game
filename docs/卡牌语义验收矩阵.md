# 卡牌语义验收矩阵（V2 · 30 张）

V2 是当前唯一正式卡牌规格。策划源表为：

- `docs/卡牌类型/主动锦囊v2.xlsx`
- `docs/卡牌类型/被动锦囊v2.xlsx`

运行时只读取 `data/generated/cards.generated.json`；源表与生成结果均为主动 15 张、被动 15 张。

## 全局语义

| 项目 | V2 规则 |
|---|---|
| 变量费用 X | 使用当前玩家剩余的全部 AP |
| 冷却 | 不设冷却区；牌可正常抽到，但倒计时结束前不能打出 |
| 被动放置 | 使用独立战门，目标键统一为 `SET_GATE` |
| 战门容量 | 敌我双方各自最多设置 3 张伏牌 |
| 手牌上限 | 全局上限为 8 张；超出上限的抽牌按规则截断 |
| 回合手牌 | 自身回合结束时，所有未使用手牌进入己方弃牌堆；神器2在战门时阻止该自动弃置 |
| 回合抽牌 | 每个自身回合开始时固定抽取 4 张牌 |
| 临时复制 | 费用为 0；使用后立即放逐，未使用则在回合结束放逐，不进入任何弃牌堆 |
| 拿来主义原牌 | 敌方原牌进入敌方弃牌堆，我方获得临时复制 |
| 机关算尽 | X 为打出时当前剩余 AP；下回合正常初始 AP 直接设置为 X+1 |
| 迷蒙指引 | 其他手牌不少于3张时弃3张；不足3张时有几张弃几张，然后继续结算 |
| 怨恨 | 每个受影响英雄在自身回合结束时移除1层 |
| 止戈 | 结算所在的不完整轮次不计，持续随后两个完整敌我轮次 |
| 背刺 | 可把攻击目标改为任意一名其他存活友方，不受相邻槽限制 |
| 神器3 | 被揭穿或离开战门后固定冷却2回合 |
| 守株待兔 | 立即检查敌方空位并取最左；兔子 30 HP、0 攻击、无职业 |
| 兔子交互 | 占据槽位；不能攻击、反击或被锦囊指定；可被敌方角色攻击 |
| 兔子胜负事件 | 不计入英雄胜负，不触发英雄死亡事件 |
| 三回合 | 按兔子所在阵营的三个完整轮计算；一张牌只生成一次 |

## 自动化入口

| 验证 | 路径 | 覆盖 |
|---|---|---|
| 数据结构校验 | `scripts/cards/CardSemanticValidator.cs` | 数量、唯一 ID、类型、战门目标、费用、稀有度、冷却、兔子数值 |
| 训练场冒烟 | `tests/training_arena_smoke.tscn` | V2 加载、Lua 语法、关键卡牌语义、UI 交互 |
| Battle UI 冒烟 | `tests/battle_ui_smoke.tscn` | 战斗 UI 和窗口适配 |
| Lua 沙盒 | `LuaCardRuntime.ValidateSandboxIsolation()` | 阻断系统、文件和 Godot 节点访问 |
