# 卡牌、英雄与怪物资源使用说明

内容数据位于 `data/`，设计人员不需要修改脚本。

## 新增内容

1. 在 Godot 文件系统面板中找到一个同类型 `.tres` 样例。
2. 右键选择“复制”，放入对应目录并重新命名。
3. 在 Inspector 中修改字段。
4. 将新资源拖入 `data/training_content.tres` 的对应数组。

目录约定：

- `data/heroes/`：英雄资源（`HeroDefinition`）
- `data/cards/`：锦囊卡资源（`CardDefinition`）
- `data/monsters/`：怪物资源（`MonsterDefinition`）
- `data/training_content.tres`：本训练场实际加载的内容清单

## 通用字段

- `id`：稳定且不可重复的内部 ID。建议只用小写英文、数字和下划线。
- `display_name`：游戏内显示名称。
- `description`：背景或功能简介。
- `artwork`：插画资源，可直接拖入图片。
- `tags`：检索、筛选和规则判断使用的标签。
- `designer_notes`：只供团队内部查看的设计备注。
- `custom_fields`：任意扩展信息。可以添加文本、数字、布尔值、数组等键值。

自定义信息示例：

```text
阵营: "守序院"
掉落权重: 20
可破坏: true
关卡限定: ["chapter_1", "chapter_3"]
```

固定战斗规则应优先增加强类型字段；仅用于试验、筛选或尚未定型的信息放入 `custom_fields`。

## 卡牌效果

`builtin_effect` 当前可直接选择：治疗、增加攻击、增加 EXP、伤害、自定义。
`effect_amount` 是对应效果数值。复杂卡牌选择“自定义”，并在 `effect_script` 中挂接后续编写的效果脚本。

## 校验

训练场启动时会检查空资源、缺失 ID 和重复 ID，并在 Godot 输出面板报告错误。
