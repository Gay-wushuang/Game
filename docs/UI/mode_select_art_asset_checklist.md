# `mode_select.tscn` 美术素材尺寸清单

## 1. 文档用途

本文依据当前场景 [`scenes/mode_select.tscn`](../../scenes/mode_select.tscn) 的真实节点范围整理，用于替换旧的 `assets/ui/mode_select.svg` 灰盒图。

- 设计逻辑画布：`1920 × 1080 px`
- 当前默认开发窗口：`1920 × 1080 px`
- Godot 使用 `1920 × 1080` 逻辑画布；在 720p 等较小窗口中通过 `canvas_items` 等比缩放，美术仍按 `1920 × 1080` 制作。
- PNG 使用 RGBA；像素素材使用 nearest 过滤并禁用 mipmap。
- 模式名称、说明文字、“敬请期待”等文字由 Godot 动态绘制，不应烘焙进底图。
- `mode_select.tscn` 明确保留玩家底栏，以延续主界面的玩家身份、等级、货币与设置入口。

## 2. 当前场景的准确热区

| 功能节点 | 左上角 `(x, y)` | 热区尺寸 | 当前行为 |
|---|---:|---:|---|
| `BackButton` | `(45, 60)` | `225 × 72` | 返回上一场景 |
| `StoryButton` | `(120, 210)` | `330 × 705` | 进入关卡选择 |
| `ChallengeButton` | `(570, 210)` | `330 × 705` | 暂未开放 |
| `ArenaButton` | `(1020, 210)` | `330 × 705` | 暂未开放 |
| `PvpButton` | `(1470, 210)` | `330 × 705` | 暂未开放 |

四个模式入口的水平间隔一致：相邻入口左上角相差 `450 px`，即卡面宽 `330 px`、空隙 `120 px`。

## 4. 模式入口分层规格

每个模式入口最终显示范围均为 `330 × 705 px`，建议在 Godot 中按以下层级组合：

```text
ModeCard 330×705
├─ Illustration       330×705
├─ GradientOverlay    330×705（程序或公共素材）
├─ Frame              330×705
├─ ModeIcon           96×96（可选）
├─ Title              Godot 动态文字
├─ Description        Godot 动态文字
├─ LockedOverlay      330×705（未开放时）
└─ InteractionArea    330×705
```

### 插画安全区

- 插画正式显示画布：`330 × 705 px`。
- 推荐提供 2 倍源图：不低于 `660 × 1410 px`，程序缩放到正式尺寸。
- 角色主体建议放在 `x = 24~306`、`y = 36~570` 范围内。
- 下方约 `135 px` 预留给模式名称、简述、开放状态或进度提示。
- 关键面部与武器不要贴近左右边缘，至少留 `24 px` 裁切安全距离。
- 插画中不得写死模式名称，避免文字与 Godot 动态文本重复。

### 公共边框

- 画布必须严格为 `330 × 705 px`。
- 外轮廓必须完整留在画布内，建议边缘透明留白 `4~8 px`。
- 中间插画区保持透明。
- 四张入口共用同一外框，颜色差异可由 Godot 调制或追加小型主题装饰实现。

### Hover 与选择反馈

- Hover 覆盖图：`330 × 705 px`，透明 PNG。
- 高亮范围不要超出画布，否则相邻入口之间可能出现裁切或鼠标区域与视觉不一致。
- 推荐只提供发光边缘、顶部亮线和轻微内发光；放大、上浮、颜色调制由 Godot 动画完成。
- 当前只有故事模式可进入，其余三个入口使用同一张 `mode_card_locked.png`。

## 6. 720p 对照尺寸

这些数值仅用于预览，不是美术交付规格。720p 下由 Godot 按 `2/3` 缩放：

| 素材/区域 | 1920×1080 逻辑尺寸 | 1280×720 屏幕显示约值 |
|---|---:|---:|
| 背景 | `1920 × 1080` | `1280 × 720` |
| 返回按钮热区 | `225 × 72` | `150 × 48` |
| 单个模式入口 | `330 × 705` | `220 × 470` |
| 模式入口间隙 | `120` | `80` |
| 模式图标 | `96 × 96` | `64 × 64` |
| 玩家底栏底板 | `1884 × 208` | `1256 × 139` |
| 玩家头像框 | `148 × 148` | 约 `99 × 99` |
| 设置按钮底板 | `150 × 150` | `100 × 100` |

不要直接按右栏的 720p 数值交付，否则在 1080p 下会被放大并降低清晰度。

│  └─ mode_select_background.png
├─ cards/
│  ├─ mode_card_frame.png

玩家底栏素材统一存放在 `assets/art/ui/common/` 并由公共 `PlayerBar` 场景复用，不要在 `main_menu/` 或 `mode_select/` 下复制第二份。

文件名使用小写 ASCII、数字和下划线。源文件可以放在同目录的 `source/` 子目录；导出的 PNG 不带文字。

## 8. 替换旧 SVG 时的验收标准

- 四个模式入口仍与原热区完全重合，不能出现“图片在这里、点击区在别处”。
- 1920×1080、1600×900、1366×768、1280×720 四档窗口均不裁掉返回按钮或模式入口。
- 720p 下文字可读，边框不因平滑缩放产生模糊细线。
- Hover、Pressed、Locked 三种状态能明显区分。
- 故事模式进入 `level_select.tscn`；其他三个入口继续显示“敬请期待”。
- 页面必须保留 `PlayerBar`，且其尺寸、数据与主界面一致。
- 正式素材接入后删除旧 `assets/ui/mode_select.svg` 中烘焙的按钮文字和底栏图像；底栏改由公共 `PlayerBar` 场景单独渲染，避免视觉重叠。
