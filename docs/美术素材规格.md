# 法则演进美术素材规格

本文件是当前项目正式美术交付基准。Godot UI、资源导入器和运行时显示应适配本规格，不再使用旧线框原型的卡牌比例。

## 正式尺寸

| 资产 | 正式规格 | 关键约束 |
|---|---:|---|
| 英雄像素立绘 | `128 × 160 px` | PNG 透明；建议主体不超过 `112 × 144 px` |
| 英雄动画单帧 | `128 × 160 px` | 每帧使用相同画布和相同锚点 |
| 卡牌正面 | `192 × 256 px` | 严格 `3:4`；动态文字不得烘焙进图片 |
| 卡牌背面 | `192 × 256 px` | 与正面外轮廓完全一致 |
| 低分辨率母版 | `96 × 128 px` | 使用最近邻放大 2 倍得到正式尺寸 |
| 独立卡牌插画 | 不低于 `384 × 288 px` | 与卡框解耦，保留二次裁切余量 |
| 英雄槽伏牌 | 约 `72 × 96 px` | 显示完整卡背，比例严格保持 `3:4` |

## 英雄素材

- 英雄立绘与动画使用透明 RGBA PNG。
- `128 × 160 px` 画布内，角色主体建议控制在 `112 × 144 px`，四周至少预留 8 px。
- 脚底基线统一在 `y = 150` 附近。
- Idle、Attack、Hit、Defeat 等动作的每帧必须保持相同画布、角色基线和锚点。
- 默认允许程序水平翻转敌方角色；具有方向性文字、徽记或不对称装备时，应另行提供敌方版本。

## 卡牌素材

- 所有卡面及卡背严格采用 `3:4`，不得拉伸适配其他比例。
- 卡名、费用、规则、数值和行动预览由程序动态绘制，不得写死在卡牌 PNG 中。
- 卡牌插画、卡框、职业标识和卡背分层保存，方便重新裁切和主题替换。
- 独立插画源图不得低于 `384 × 288 px`；关键主体不要贴边。
- 英雄槽内伏牌使用完整卡背等比缩放到约 `72 × 96 px`，不另做小尺寸图标。

## 导入设置

- 像素素材使用 nearest 过滤。
- 禁用 mipmap 和会破坏像素边缘的平滑缩放。
- 低分辨率母版只允许以整数倍率放大；`96 × 128 px` 使用最近邻放大 2 倍得到 `192 × 256 px`。

## 推荐路径

```text
assets/art/heroes/<hero_id>/
assets/art/cards/illustrations/
assets/art/cards/templates/
assets/art/animations/<entity_id>/
```

文件名使用小写 ASCII、数字和下划线。原始 `.aseprite` 文件可放入对应目录的 `source/` 子目录，并使用 Git LFS 管理。
