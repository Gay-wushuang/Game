# 主动锦囊牌（第二批·新增15张）

> 本文档为第二批15张新增主动锦囊牌的设计稿，编号 TA-016 ~ TA-030。
> 设计基于《法则演进》项目现有15张主动锦囊（TA-001 ~ TA-015）进行扩展，引入10个新机制。
> 所有卡牌遵循 V2 战斗流程与全局资源规则：每回合5点行动力、手牌上限8张、回合结束弃置未使用手牌。
> 标注"解放机制"的卡牌在英雄升星后获得增强效果，星阶阈值以使用该锦囊的英雄当前星级为准。
>
> **状态：批准设计，尚未实现。** 本文定义第二批扩展内容，不表示这些卡牌已经进入 `cards.generated.json` 或当前牌池。实现时必须同步V2源表、生成数据、Lua/C#、AI、UI、保存恢复及Smoke。
>
> **星阶参考英雄**：打出本批主动锦囊前必须先指定1名存活友方英雄作为“使用者英雄”，其星级决定解放分支；该指定不消耗该英雄的攻击或技能机会。牌面另有我方目标时，默认该目标同时是使用者英雄；无我方目标的牌仍需单独选择使用者英雄。

## 二、卡牌详情

### TA-016 破釜沉舟

- **分类**：主动类锦囊
- **基础费用**：1点行动力
- **目标**：选择1名我方英雄，再选择1名敌方英雄
- **效果文本**：选择1名我方英雄，消耗其当前生命值的20%（四舍五入），对1名敌方英雄造成等同于消耗生命值2倍的普通伤害（四舍五入）。
- **关键词**：献祭，生命消耗，双倍伤害
- **稀有度**：3
- **冷却**：0
- **机制**：献祭机制
- **解放机制**：3星以上——消耗比例从20%提升至30%，伤害倍率从2倍提升至2.5倍
- **策划备注**：消耗不视为受到伤害，不触发反伤、止戈等受伤后效果；消耗后英雄生命值最低为1；若英雄当前生命值为1则无法选择

### TA-017 连环计

- **分类**：主动类锦囊
- **基础费用**：1点行动力
- **目标**：无
- **效果文本**：打出后获得连锁标记：本回合下一张主动锦囊费用-1；若该牌支付前最终费用已经为0，则不再减费并在该牌结算后抽1张。连锁标记在尝试打出下一张主动锦囊时消耗。
- **关键词**：连锁，费用减免
- **稀有度**：4
- **冷却**：0
- **机制**：连锁机制
- **解放机制**：3星以上——回合结束时未消耗的连锁标记保留到下个自身回合结束；4星以上——费用减免提升至-2
- **策划备注**：连锁标记为buff类，可清除且不可叠加；减费不适用于 `VARIABLE_AP` / `ALL_CURRENT` 费用牌；目标或其他合法性检查失败时不消耗标记，正式支付并打出时才消耗

- **效果文本**：选择1名我方英雄获得2层蓄力；蓄力期间该英雄当前攻击力+20%（四舍五入）；该英雄每个自身回合结束时移除1层蓄力；蓄力归零时该英雄立即发动1次额外普通攻击。

## 三、设计说明

### 3.1 设计目标

第二批15张主动锦囊在现有15张（TA-001 ~ TA-015）的基础上，从以下维度扩展战术空间：

1. **资源博弈深化**：献祭、吞噬、连锁、反噬等机制让玩家在代价与收益之间做出更丰富的权衡。
2. **时间维度策略**：蓄力、时滞、印记等机制引入延迟结算，让玩家可以布局未来回合。
3. **克制关系突破**：暗度陈仓仅绕过该次普通攻击对应的敌方攻击前/伤害前战门响应与反伤，破局者在劣势时提供阶段性增益。
4. **信息与控制**：偷天换日、釜底抽薪提供信息优势和手牌干扰，丰富非伤害型策略。

### 3.2 费用与稀有度分布

| 1 | 7 | 47% |

低费卡占多数，与现有15张牌的费用结构一致，确保玩家每回合5行动力下有充分的选择空间。

| 机制 | 引入卡牌 | 类型 |
|---|---|---|
| 献祭机制 | 破釜沉舟 | 代价型 |
| 连锁机制 | 连环计 | 增益型 |

### 3.4 与现有卡牌的协同与差异

| 新卡 | 与现有卡的差异/协同 |
|---|---|
| 破釜沉舟 | 区别于暴力手段（固定伤害）：以自伤为代价换取更高伤害上限 |
| 连环计 | 与机关算尽（费用管理）协同：连锁减费+透支可形成费用引擎 |
| 蓄势待发 | 区别于村好剑（即时额外攻击）：蓄力提供持续增益+延迟终结效果 |
| 移花接木 | 与怨恨（施加debuff）互补：移花接木直接夺取敌方正面增益 |
| 焚书坑儒 | 与侦查（从牌堆选牌）形成对比：吞噬消耗弃牌堆而非利用它 |
| 金蝉脱壳 | 区别于重甲（护盾减伤）：时滞免疫致命伤害，更精准但不可清除 |
| 烈焰印记 | 区别于怨恨（攻击削弱）：印记造成持续直接伤害，不随回合减少 |
| 破镜重圆 | 专门克制共鸣机制，丰富反制手段 |
| 天降神兵 | 唯一改变英雄数量的锦囊，与部署节奏产生新战术 |
| 反噬之咒 | 区别于暴力手段（单体伤害）：以己方全体伤害为代价换取AoE |
| 偷天换日 | 区别于拿来主义（偷手牌）：从弃牌堆窃取，信息更明确 |
| 休养生息 | 区别于妙手回春（单体回复）：群体回复但附带攻击限制 |
| 暗度陈仓 | 限定绕过该次普通攻击的攻击前/伤害前战门响应与反伤，不关闭其他事件 |
| 破局者 | 劣势翻盘卡，与特限机制结合实现一次性爆发+后续持续增益 |
| 釜底抽薪 | 唯一干扰敌方手牌的锦囊，提供非伤害型控制手段 |
