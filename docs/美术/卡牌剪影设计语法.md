# 卡牌剪影设计语法 V1.0

> 适用范围：当前 V2 主动锦囊与被动锦囊，共 30 张。
> 冻结尺寸：`168 × 224 px`，严格 `3:4`。
> 数据依据：`data/generated/cards.generated.json`。

## 一、设计定义

卡牌视觉使用以下固定公式：

```text
卡牌视觉 = 完整插画核心 + 类型剪影 + 少量类型色
类型剪影 = 一级姿态 + 二级运动 + 次级修饰 + 三级题材词汇
```

剪影不是完整卡框，也不是任意装饰。它承担卡牌类型识别、视线导向和文字暗区组织三项职责。

### 母原则

- 插画核心必须完整，不能为了剪影效果切掉主体的脸、手、武器或关键叙事物。
- 不使用四边闭合的传统完整卡框；剪影边界必须有断口和留白。
- 类型首先靠轮廓运动识别，颜色只作辅助，不能仅凭换色区分类型。
- 剪影自然形成深色信息承载区，白色动态文字直接落在暗区内。
- 动态文字、名称、费用和数值不得烘焙进美术素材。
- 像素边缘使用硬边和最近邻显示；不使用模糊、软羽化或大面积 Bloom。
- 每张牌只能有一个“主功能节点”。复合效果写成次级修饰，不能混合两套同等强度的主轮廓。

## 二、三层语法

### 1. 一级：卡牌大类姿态

#### 主动 `ACTIVE`

```text
ACTIVE := 外放 + 破边 + 非对称 + 明确方向
```

- 主要占据 1～2 个边。
- 优先从侧边、左下或右下生长。
- 必须留下一个清楚的出手方向。
- 暗区可以倾斜或被切开，不应形成安稳的封闭底座。

视觉含义：发动、释放、干预、立即行动。

#### 被动 `PASSIVE`

```text
PASSIVE := 附着 + 包覆 + 稳定 + 条件蓄势
```

- 可沿底边和侧边形成较连续的承载面，但仍需保留断口。
- 主体姿态稳定，触发方向通过局部缺口、尖刺或折返表达。
- 暗区比主动牌更完整，适合承载持续规则和触发条件。

视觉含义：设置、维持、守候、条件生效中。

### 2. 二级：主功能运动

| 功能节点 | 运动动词 | 轮廓语法 | 禁忌 |
|---|---|---|---|
| `ATTACK` 攻击 | 外冲、撕裂、斜切 | 尖角、爪痕、刀口、爆裂缺口 | 圆润闭合、静态装饰带 |
| `CONTROL` 控制 | 收束、缠绕、压入 | 双侧夹合、环扣、锁口、向内回卷 | 过度舒展、单纯向外爆发 |
| `SUPPORT` 支援 | 托举、展开、向上 | 底部抬升、上扬弧线、充足留白 | 压迫、重尖角、向下坠落 |
| `DEFENSE` 防御/反击 | 格挡、迎击、折返 | 盾缘、折角、外层护片、局部回刺 | 全面闭缩、纯攻击式前扑 |
| `RESOURCE` 资源/调度 | 流动、输送、汇聚 | 流线、片层、入口与出口、循环路径 | 厚重封死、无方向堆纹 |
| `SUMMON` 召唤/展开 | 打开、生成、显现 | 门隙、法阵开口、扇面外扩、中心涌出 | 与攻击相同的单向劈砍 |

### 3. 次级修饰符

次级修饰只允许占主剪影视觉权重的约 20%～30%。

| 修饰符 | 局部语义 | 表现方法 |
|---|---|---|
| `COUNTER` 反制 | 待机后回刺 | 在稳定外缘增加一个反向尖角或折返缺口 |
| `SUSTAIN` 持续 | 维持、常驻 | 增加沿边连续段或闭合趋势，但不得形成完整框 |
| `DELAY` 延迟 | 尚未完成 | 留出断点、未闭合回路或分段刻度 |
| `REVIVE` 复活 | 断而重连 | 断裂两端重新接续、底部回托 |
| `COPY` 复制 | 镜像、复写 | 一主一次的错位重影，不能复制整套边框 |
| `EXILE` 放逐 | 消散、不可回收 | 边缘向外碎解或形成单向离场缺口 |
| `RANDOM` 随机 | 不稳定分岔 | 局部二分路径或不等长分叉 |
| `GLOBAL` 全体 | 范围扩散 | 在主方向之外加入短小环向扩散 |
| `COST` 费用 | 输入、阻滞 | 流路上的节点、闸口或配重块 |

### 4. 三级：题材词汇

```text
THEME := 世界观材质 × 角色/阵营身份 × 元素意象
```

可用词汇包括毛束、羽翼、披帛、火舌、刀锋、锁链、星轨、徽记、光带、机械片、幽影和法阵。题材只能翻译二级运动，不能反过来改变功能语法。

例如：

```text
狼系攻击 = ATTACK 的外冲运动 + 毛束/爪痕
星轨攻击 = ATTACK 的外冲运动 + 破碎星轨
圣职支援 = SUPPORT 的托举运动 + 披帛/光带
机械控制 = CONTROL 的收束运动 + 卡扣/齿轮锁
```

## 三、构图与像素约束

### 逻辑区域

| 区域 | 建议范围 | 作用 |
|---|---:|---|
| 卡牌画布 | `168 × 224` | 固定逻辑尺寸 |
| 外沿安全区 | 四周至少 `8 px` | 防止 Hover、裁切和像素跳边 |
| 插画核心区 | 中上部约 60%～70% | 保证主体叙事完整 |
| 信息暗区 | 下部约 25%～35% | 承载名称、类型与动态规则摘要 |
| 剪影占边 | 主动 1～2 边；被动 2～3 个局部边段 | 保持非完整边界 |

这些范围是构图约束，不是要求所有卡牌共用同一块矩形暗板。暗区必须由剪影自然形成。

### 类型色

- 主色仍由插画和阵营题材决定。
- 类型色只用于剪影内缘、高光断点和少量识别标记。
- 同一功能节点使用相近明度与饱和度关系，不要求所有牌使用完全相同的 RGB。
- 必须保证去色后仍能通过轮廓区分类型。

## 四、正式语法树

```text
CARD
├─ ACTIVE 主动：外放 / 破边 / 非对称 / 有方向
│  ├─ ATTACK 攻击：外冲 / 撕裂 / 斜切
│  ├─ CONTROL 控制：收束 / 缠绕 / 压入
│  ├─ SUPPORT 支援：托举 / 展开 / 向上
│  ├─ DEFENSE 防御反制：格挡 / 迎击 / 折返
│  ├─ RESOURCE 资源调度：流动 / 输送 / 汇聚
│  └─ SUMMON 召唤展开：打开 / 生成 / 外扩
└─ PASSIVE 被动：附着 / 包覆 / 稳定 / 条件蓄势
   ├─ ATTACK 攻击触发：稳定基底 + 突发外冲
   ├─ CONTROL 控制触发：稳定包边 + 收束锁口
   ├─ SUPPORT 持续支援：包覆 / 托举 / 维持
   ├─ DEFENSE 防御反击：护层 / 回刺 / 折返
   ├─ RESOURCE 资源转化：回路 / 吸纳 / 导出
   └─ SUMMON 召唤展开：门形附着 + 条件开启
```

当前 V2 没有以 `ACTIVE/SUMMON` 为主节点的卡牌。该节点作为正式扩展语法保留，不能为了填满分类而强行归入其他卡牌。

## 六、分类决策说明

以下复合牌容易产生归类歧义，现统一按“主要视觉动作”冻结：

- `重甲`：虽然属于增益，但主要动作是承受伤害，因此归入 `DEFENSE`。
- `拒绝生效`：它是主动打出的反制准备，一级仍是主动，二级归入 `DEFENSE`。
- `同甘共苦`、`村好剑`：核心是强化我方英雄，归入 `SUPPORT`；攻击性只作局部修饰。
- `怨恨`：效果作用于全体，但主要动作是压低敌方能力，归入 `CONTROL`。
- `神圣的降临`、`神器3`、`赌`、`以偏概全`：共同核心是改变手牌或 AP 流转，归入 `RESOURCE`。
- `背刺`：不是直接造成伤害，而是迎击并改变攻击路径，归入 `DEFENSE/COUNTER`。
- `守株待兔`：核心是生成占位单位，唯一归入 `PASSIVE/SUMMON`；延迟爆炸只作为修饰。

## 七、制作与验收流程

每张卡在绘制前填写一行设计句：

```text
[大类] + [主功能] + [次级修饰] + [题材词汇] + [主要生长方向]
```

示例：

```text
守株待兔 = PASSIVE + SUMMON + DELAY/GLOBAL + 兔形幽影/陷阱门 + 由内向外开启
目中无人 = ACTIVE + ATTACK + 无修饰 + 星轨切线 + 左下向右上贯穿
神器1 = PASSIVE + SUPPORT + SUSTAIN/GLOBAL + 学院光环 + 底部向两侧包覆
```

交付前逐项检查：

1. 缩略到实际 `168 × 224` 后，能否只看黑色轮廓判断主动或被动。
2. 去掉颜色后，能否判断其主功能运动属于哪一类。
3. 插画主体是否仍然完整，剪影是否没有遮挡关键叙事物。
4. 是否存在自然且足够稳定的文字暗区。
5. 是否错误画成完整闭合卡框。
6. 次级修饰是否压过主功能轮廓。
7. 同类型卡是否共享运动语法，同时又能通过题材词汇区分。

若 1、2、5 任一项不通过，应回到类型语法重画，而不是依靠增加颜色、纹理或说明文字补救。
