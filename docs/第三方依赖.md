# 第三方依赖

## Lua GDExtension

- 项目：`gilzoide/lua-gdextension`
- 版本：`0.8.2`
- 许可证：MIT，许可证副本位于 `addons/lua-gdextension/LICENSE`
- 用途：为 Godot 4.7 .NET 提供隔离的 Lua 5.4 状态，用于少量复杂卡牌规则。
- 当前仓库仅提交 Windows x86_64 的调试和发行二进制；增加其他导出平台时，应从同版本官方发行包补充对应库并更新 `.gitignore`。

项目不会把 Lua 作为 Godot 节点脚本语言使用，也不会向卡牌 Lua 状态开放 Lua 标准库或 Godot API。Lua 只能调用 `LuaCardRuntime` 注入的白名单函数。
