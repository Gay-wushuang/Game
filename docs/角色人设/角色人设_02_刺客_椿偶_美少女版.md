# 角色人设设定书 · 02（美少女版）

> **文档定位：正式角色叙事与概念美术基准。** 玩法数值和技能结算以 `docs/英雄类型/角色2.md` 与运行时英雄资源为准；本文的复杂服饰和特效用于高精度概念图，落地 `128×160` 像素战斗立绘时必须按安全区做取舍。

## ── 刺客「椿偶」 ──

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 以日式传统人偶美学为基底，融合哥特式傀儡元素与美少女的精致面庞。赛璐璐上色强调瓷器般的肤质、木质关节的机械感，以及和风纹样的平面装饰性。她是「美到令人不安」的人偶少女——太过完美的对称面容、太过空洞的红色眼眸、太过宁静的微笑。

## 二、角色背景故事

「椿偶」原本是暗杀组织「落椿流」用于训练新人的活体木桩——一具被施加了禁术的战斗人偶。她由千年椿木雕刻而成，以少女为原型，关节处嵌有咒术铁环，可以模拟人类的战斗动作。新人刺客们反复对她进行刺杀训练，而她也在无尽的被击打中，逐渐产生了自我意识。

她不理解疼痛，却能感受到每一次刀刃切入身体时，某种「渴望」在生长——不是对生存的渴望，而是对「攻击」本身的渴望。某一天，她在训练中第一次主动挥刀，斩杀了面前的训练生。从此，「训练用的人偶少女」成为了最危险的刺客。

她的口头禅是：「疼痛……是什么？教教我。」

> **美少女特征要点**：属于「诡异美人」型角色——外表是无害的精致少女，黑发红瞳、瓷白肌肤、樱桃小嘴的微笑，却透着令人背脊发凉的空洞。她的美在于「不完整感」：球体关节的接缝、胸口宝石的裂纹、背后无形的操控线，都在暗示这个美丽的少女不是人。她是四人中体型最小、面容最精致、杀伤力却最高的一个。

## 三、外貌设计

### 3.1 面部特征

- **脸型**：精致的鹅蛋脸，下巴尖削，面部完全对称（人偶的完美对称感）。五官小巧精致，是那种「被人精心雕刻出来的美」——毫无瑕疵，反而显得不真实
- **眼睛**：大而圆的杏眼，虹膜为深椿红色（#7A1A2A），瞳孔为空心圆环（无人的空洞感）。赛璐璐处理时瞳孔内不做星光高光，仅一个圆形高光点，显得空洞而美丽。那双红色大眼睛配上少女的面庞，像是一双会发光的红宝石
- **眉毛**：极细的柳叶眉，用单线勾勒，眉形柔和
- **鼻子**：小巧挺直，鼻尖极小，精致如瓷
- **嘴唇**：樱桃小嘴，上唇薄下唇略厚，嘴角永远微微上扬，形成一种"似笑非笑"的诡异表情。唇色为自然的淡樱粉
- **面部接缝**：面部沿发际线、耳前、下颌有一圈极细的拼接缝线（人偶球体关节的接合痕迹），用比肤色深两号的细线表现。这些接缝在她白皙的脸上若隐若现，是「她不是人」的标记
- **肤色**：瓷白近乎无血色（#E8D8D0），赛璐璐处理时刻意减少皮肤阴影层次，营造人偶的无机质感

### 3.2 发型发色

- **发色**：纯黑色（#1A1A1A），发梢处渐变为深椿红色（#5A1A2A），如同椿花染血
- **发型**：长直发，及腰长度。前额为整齐的齐刘海，exact cut平切。两侧各有一束头发编成细辫，辫尾系有红色丝带和小椿花饰。黑发衬着瓷白的小脸，反差极大
- **质感表现**：头发用大块纯黑填充，赛璐璐高光为一条贯穿头顶的蓝紫色反光带（#4A3A5A），发梢红色部分用渐变色块但边缘仍保持硬切

### 3.3 体型身姿

- 纤瘦娇小的少女体型，肩窄腰细，四肢纤细。是四人中体型最小巧的一个
- **核心特征——球体关节**：肩膀、手肘、手腕、膝盖、脚踝处可见明显的球形关节结构，关节球为深木色（#5A3A2A），接缝处有黑色细线。关节处的机械感与她少女的柔美身体形成诡异的并存
- 站姿略微歪头，身体重心偏向一侧，双手自然垂下但手指微微弯曲如待握物
- 给人一种「不自然的静止」感——像美丽的少女人偶被突然定格

## 四、服装设计

### 4.1 主体服装——和风战斗装束

- **上半身**：黑色紧身打底衣，外罩一件无袖的深绯色（#6B1A2A）和风短上衣，衣襟交叠呈V形，露出锁骨和小片瓷白胸口。上衣下摆呈不规则锯齿状（模仿椿花瓣边缘），锯齿下摆如短裙般垂在腰间
- **下半身**：不对称裙裤设计——左侧为黑色紧身短裤，右侧为垂至膝盖的深绯色侧裙片，裙片上绣有白色椿花散落纹样。裙片在行动时飘动，露出纤细的膝盖和球体关节
- **腰部**：宽幅黑色织带腰带，系扣方式为和风蝴蝶结，结头垂下两条飘带，飘带末端系有小铃铛。腰带宽大，衬得她本就纤细的腰身更加娇小

### 4.2 护甲元素

- **肩甲**：无金属肩甲，取而代之的是左右各一块椿花形肩饰，木质雕刻，涂深红漆。花形肩饰落在她窄小的肩头上，像是真的花朵落在了那里
- **臂甲**：前臂缠绕黑色绷带，从手腕缠至肘下，绷带间露出苍白的皮肤和球体关节。右手前臂绑有一块小型木质护臂
- **腿甲**：左小腿绑有木质胫甲一块，右侧无甲。木质护甲与她纤细的小腿形成质感对比

### 4.3 人偶特征元素（核心视觉特征）

- **背部**：背部可见四条细线从肩胛骨处延伸而出，如同提线木偶的操控线，线条为暗红色半透明，末端消失于虚空（暗示她仍在被某种力量操控）。操控线连接在少女纤细的后背上，画面诡异而美丽
- **胸口**：胸口正中嵌有一颗拳头大小的椿花形红色宝石，这是她的「核心」——生命力的来源。宝石内有裂纹（对应自伤机制）。宝石镶嵌在少女平坦的胸口正中央，如同一颗心脏被外置
- **关节**：所有暴露的球体关节上刻有细小的咒文，用金漆填写。关节转动时金色咒文若隐若现

## 五、配饰与道具

### 5.1 武器——「落椿」双扇刃

- **形态**：一对折叠战扇，扇骨为黑铁，扇面为深红色绢丝，扇缘暗藏锋利刃口
- **展开态**：扇面完全展开时呈半圆形，绢面上绘有白色椿花飘落图样
- **收纳态**：折叠后为短棍状，可插于腰后
- **赛璐璐表现**：扇骨用黑色填充+银色刃口高光线，扇面用深红平涂+白色椿花纹样叠加，纹样不做立体处理，保持平面装饰感

### 5.2 其他配饰

- **头部**：左侧发间别一朵红色椿花发饰，花瓣为木质雕刻涂漆。花朵衬在黑发间，映衬她瓷白的小脸
- **颈部**：戴有一条黑色细绳项链，坠子是一颗小木珠（人偶的「灵魂核」碎片）。细绳缠绕在她细长的脖颈上
- **手部**：十指指尖涂有深红色指甲油，与椿花主题呼应。纤细白皙的手指上红甲如血
- **足部**：穿黑色分趾足袋+木齿木屐，走路时发出清脆的叩地声。小木屐与她的体型形成滑稽的比例

### 6.2 赛璐璐色阶规则

- 皮肤：仅两层色阶（底色+一块阴影），刻意减少层次以营造瓷器般的平面感
- 衣物：三层标准色阶，阴影切割方向统一
- 木质关节：两层色阶+金色咒文线描
- 整体上色偏好「少阴影、大色块」，模拟日式传统绘画的装饰性平面感

## 七、赛璐璐风格表现要点

### 7.1 线稿

- 线条整体偏细，粗细变化不大，营造精致人偶的工艺感
- 面部五官用极细线（0.5px），关节接缝用虚线表现
- 头发外轮廓线略粗（1.5px），内部发丝不分股，仅用大色块
- 椿花纹样的轮廓线用金色（#C8A038）而非黑色，增加和风装饰感

### 7.2 上色

- 皮肤上色刻意减少阴影层次，仅在下巴底、刘海下、关节缝处添加阴影，营造人偶的「无血色」感
- 衣物褶皱用简洁的几何阴影块表现，不做柔和过渡
- 椿花纹样直接平涂叠加在衣物色块上，无立体感，保持和风织物的平面装饰美学
- 头发高光为一条连贯的反光带，不分段

### 7.3 特效层

- **被动激活（主动攻击+5ATK）**：双扇刃展开，刃缘浮现红色锋芒线
- **技能激活（自伤换攻击）**：胸口的椿花宝石裂纹扩大并发红光，少女瓷白的身体表面浮现蛛网状裂纹纹路，代表「自损」
- **队长加成（反击+5ATK）**：背后的人偶操控线亮起红光，呈绷紧状态
- **6星觉醒**：人偶操控线断裂，背后出现巨大的椿花虚影

## 八、表情与姿态设计

### 8.1 默认立绘姿态

- 正面站立，身体微微歪头15度向左倾，重心偏右
- 右手展开一把落椿扇，扇面半遮面部下半，仅露出空洞的红色大眼眸
- 左手自然下垂，手指微曲如提线木偶的放松态
- 双脚并拢，木屐轻踩地面
- 背后四条操控线在空中微微飘动

### 8.2 表情变化

| 状态 | 表情描述 |
|------|----------|
| 默认 | 似笑非笑，嘴角微翘，红色大眼空洞无神。少女的美丽面庞上挂着一种「不知道在想什么」的微笑 |
| 攻击时 | 头部歪向一侧，嘴角弧度加大露齿，眼睛圆睁但瞳孔依旧空洞。歪头的角度不似人类，更像人偶的关节转动 |
| 技能自伤时 | 嘴角下垂（唯一一次不笑的表情），眼中浮现一丝红色裂纹光。瓷白的脸上出现裂纹纹路，像是美丽的瓷器即将碎裂 |
| 反击时 | 表情不变，但头部以不自然的角度旋转（人偶特征）。微笑的脸转向身后，如同灵异片中的画面 |
| 6星觉醒 | 操控线断裂，表情从空洞变为有神，红色眼眸中第一次倒映出真实的光。嘴角流下一滴红色泪珠——人偶少女学会了悲伤 |

## 九、设计元素与游戏机制关联

| 游戏机制 | 对应设计元素 |
|----------|-------------|
| HP=70（低血量） | 人偶躯体纤瘦娇小，关节处可见拼缝，暗示「易碎」 |
| ATK=20（最高攻击） | 双扇刃为最锋利武器，指尖红如染血，攻击性视觉强化。最无害的外表下藏着最锋利的杀意 |
| 自伤换攻击力 | 胸口宝石有裂纹，瓷白身体表面可浮现裂纹——视觉化「以自身破损换取力量」，如美丽瓷器碎裂出力量 |
| 反击加成 | 背部提线暗示「被操控反击」的概念，人偶少女的被动性——她攻击时到底是谁在操控？ |
| 名为「训练用木桩」 | 整体设计为战斗人偶少女，球体关节+木质材质+操控线 |
| 被动「主动攻击+5ATK」 | 双扇刃展开的攻击态势，锋芒毕露 |
| 6星失去职业 | 操控线断裂=挣脱操控=脱离「刺客」身份，人偶少女获得了自我意识与真正的情感 |

## 十、标志性画面

### 概念场景描述

「训练场上，新人刺客举刀刺向木桩。刀刃没入——那张精致的面庞缓缓转向他，嘴角弯起一个从没有人见过的弧度。她抬手展开折扇，扇面的椿花仿佛真的在飘落。那张美丽的少女面孔带着微笑，空洞的红色大眼睛直直地望着他。新人来不及惨叫。」

> 画面构图：俯视角度，画面中央是椿偶单手展开折扇遮面的站姿，娇小的身形站在倒下的训练生身旁。扇面上的白色椿花从绢面飘出，化为真实的血色花瓣散落在画面中。她的球体关节清晰可见，背后的操控线绷直延伸向画面外的黑暗。一双空洞的红色大眼睛从扇面上方凝视观者——少女的美丽面庞上，那抹微笑令人毛骨悚然。

## 十一、升星视觉变化一览

| 星级 | 视觉变化 |
|------|----------|
| 1星 | 扇刃边缘多出一道红色锋芒线 |
| 2星 | 攻击时眼睛短暂出现瞳孔（从空洞变为有焦点） |
| 3星 | 身体表面的裂纹纹路变为暗金色（反伤减免可视化） |
| 4星 | 双扇增大，扇面椿花纹样变为金色 |
| 5星 | 胸口宝石裂纹修复（自伤代价降低），宝石光泽更亮 |
| 6星 | 操控线全部断裂化为碎片，背后绽放巨大椿花虚影，面部接缝线消失——人偶少女「活」了过来，瓷白的脸上第一次有了真实的血色。脱离刺客职业的傀儡身份，从一个被操控的美丽人偶变成了一个会流泪的少女 |
