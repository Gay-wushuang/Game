## 01 · 荆铁「先锋」

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 线条清晰锐利，色块分明，阴影采用硬边切割，高光集中于金属边缘与瞳孔，整体呈现日式动画般的平面化质感。人物造型为高挑挺拔的骑士少女，硬朗铠甲与少女身形形成鲜明反差。

### 一、角色基本信息

| 项目 | 内容 |
|------|------|
| 角色名 | 荆铁（Jīng Tiě） |
| 职业 | 先锋 |
| 定位 | 前排坦克 / 伤害吸收 / 团队护盾 |
| 身高 | 172cm |
| 体型 | 高挑匀称，肩背线条利落，四肢修长有力，属于「穿衣显瘦、脱衣有肌」的运动员体态 |
| 年龄外观 | 19岁左右 |
| 性别 | 女 |
| 基础HP | 150 |
| 基础ATK | 8 |

### 二、角色背景故事

荆铁曾是北境边塞「铁壁军团」中最年轻的副将，以一人之力镇守关门三日不死，被士兵们称为「不倒的铁壁姬」。在一次惨烈的守城战中，她主动替战友挡下了致命的魔法轰击，全身被荆棘魔法侵蚀。此后她的铠甲与血肉共生，荆棘从铠甲缝隙中生长，成为一种活体护甲——越是受伤，荆棘越是茂密，防御反而越强。

她沉默寡言，习惯站在最前方承受一切，面容常年冷峻，却会在队友受伤时默默将自己的披风盖在对方身上。不善于表达感情，所有关心都化作行动。口头禅是：「站在我身后。」

> **美少女特征要点**：属于「可靠大姐姐」型角色——高挑、冷峻、寡言，但骨子里极重感情。她的美不在于柔媚，而在于那种「即使遍体鳞伤也绝不后退一步」的凛然英姿。荆棘从少女白皙的皮肤上生长，铁与花的共生构成独特的暴力美学。

### 三、外貌设计

#### 3.1 面部特征

- **脸型**：修长的鹅蛋脸，下颌线利落分明，轮廓介于少女的柔和与武人的刚毅之间
- **眼睛**：窄长凤眼，微微上挑，虹膜为暗金色（#C8A038），瞳孔为竖线状，战斗时会微微发光。赛璐璐处理时采用双色瞳孔——外圈深金、内圈亮金高光点。眼尾微翘，冷冽中透出一丝英气
- **眉毛**：英气剑眉，略微偏粗，左眉有一道斜向伤疤，伤痕切断了眉形
- **鼻子**：高挺鼻梁，鼻梁窄而精致
- **嘴唇**：薄唇，唇色偏淡，嘴角微微下压，表情常年严肃。偶尔在队友看不到的角度会露出一丝极浅的笑意
- **伤疤**：左脸颊至颧骨处有一道显眼的战伤疤痕，呈锯齿状（荆棘划痕）。伤痕横过白皙的面庞，构成一种「带着伤疤也很美」的硬朗吸引力

#### 3.2 发型发色

- **发色**：钢铁灰白（#B8B8C0），发根处偏深铁灰色，发梢渐变为银白
- **发型**：齐耳短发的利落造型，后颈处发尾微翘。头顶前方有一撮向上翘起的呆毛（赛璐璐风格中作为角色辨识点，用硬边色块表现）。左侧鬓角留一束较长碎发垂至脸颊，恰好遮住部分伤疤
- **质感表现**：发丝不细分，用大色块铺底色，留出1-2道银白色高光条。短发造型凸显她干练利落的性格

#### 3.3 体型身姿

- 高挑匀称的少女体型，肩线平直而略宽（但不失女性线条），腰背紧实，双腿修长
- 站姿微微前倾，重心下沉，双手习惯性握拳垂于身侧
- 宽厚的肩甲使整体轮廓呈梯形，但铠甲缝隙处露出的肢体线条依然纤细
- 赛璐璐表现时强调肩部、胸甲、护腿的几何块面感，同时在铠甲间隙用细线勾勒少女的肢体轮廓，形成「重甲之下是纤细身躯」的对比

### 四、服装设计

#### 4.1 铠甲主体

- **胸甲**：厚重的板甲胸铠，正面铸有荆棘缠绕盾牌的纹章。胸甲表面有明显的锤打纹理，用赛璐璐方式处理为两层色阶——基底钢铁蓝灰（#5C6B7A），高光面为浅银灰（#A8B5C0）。胸甲成型贴合女性躯干，腰部收窄
- **肩甲**：左右不对称设计。左肩为巨型兽首肩甲（狮鹫头造型），右肩为常规板甲。肩甲边缘有荆棘纹饰向外延伸。左肩甲略显庞大，与少女的肩线形成夸张比例，强化「以小身躯扛重甲」的视觉冲击
- **臂甲**：前臂覆有层叠式板甲护臂，关节处可见锁子链环连接。臂甲与裸露的上臂形成对比——金属的粗粝与少女手臂的白皙
- **腿甲**：大腿至膝盖为全覆式板甲，小腿为胫甲+锁甲裙摆。大腿铠甲与大腿之间的缝隙露出深绯色战袍衬里和一小段白皙皮肤

#### 4.2 内衬衣物

- 铠甲内穿深绯红色（#8B2D2D）的厚织物战袍，从铠甲缝隙处露出。战袍为立领长袖款式，领口微微敞开露出锁骨
- 战袍下摆呈不规则撕裂状，边缘有焦痕，从腿甲下方露出如短裙般的碎裂布片
- 腰间系有宽大的黑色皮带，皮扣为荆棘花纹金属扣。皮带勒紧腰线，强调她窄而紧实的腰身

#### 4.3 荆棘共生元素（核心视觉特征）

- 从铠甲的缝隙（颈部、肩关节、腰侧）生长出黑铁色的荆棘藤蔓，藤蔓缠绕在少女白皙的皮肤上，形成「花与铁」的视觉张力
- 荆棘上偶有暗红色小花苞，代表她的生命力——HP越低荆棘越茂密（可作为受伤状态的视觉变化）
- 赛璐璐处理：荆棘用纯黑勾线，填充深墨绿色（#2A3A2A），尖刺处点白色高光。荆棘爬过少女皮肤的部分，用极细的暗红线描表现藤蔓与皮肤的交界

### 五、配饰与道具

#### 5.1 武器——「壁垒」巨盾

- **形态**：人高的塔盾，盾面宽厚，顶部呈V形缺口。盾牌竖立时几乎可以遮住她的半个身躯，形成「娇小少女+巨盾」的经典反差
- **材质**：黑铁铸造，盾面刻有荆棘缠绕城墙的浮雕
- **细节**：盾牌背面嵌有一面小镜（用于反射光线信号），盾缘包铜
- **赛璐璐表现**：盾面用三段色阶表现金属质感——暗面（#3A4550）、中间调（#6B7B8A）、高光面（#C0CCD8），边缘锐利切割

#### 5.2 其他配饰

- **颈部**：戴有一条粗铁链项链，坠子是一枚残破的军徽（铁壁军团标志）。铁链衬托在修长的脖颈上，粗粝金属与白皙皮肤形成对比
- **右手**：无名指上有一枚黑色铁戒，戒面刻有"守"字
- **披风**：无长披风（避免遮挡铠甲设计），取而代之的是腰后挂有一截断裂的战旗旗杆，旗面已残破不堪。战旗旗面偶尔会被她取下，披在受伤的队友身上

### 六、色彩设计

#### 6.1 主色调

| 色彩位置 | 颜色 | 色值 |
|----------|------|------|
| 铠甲基底色 | 钢铁蓝灰 | #5C6B7A |
| 铠甲高光 | 浅银灰 | #A8B5C0 |
| 铠甲暗部 | 深铁灰 | #2A3540 |
| 内衬战袍 | 深绯红 | #8B2D2D |
| 荆棘藤蔓 | 深墨绿 | #2A3A2A |
| 荆棘花苞 | 暗血红 | #6B1A1A |
| 发色 | 钢铁灰白 | #B8B8C0 |
| 瞳色 | 暗金色 | #C8A038 |
| 皮肤 | 白皙微麦 | #E8C8B0 |

#### 6.2 赛璐璐色阶规则

每个色彩区域严格分为三层色阶：
- **底色层**：主色调，占面积最大
- **阴影层**：底色降两阶，硬边切割，集中在背光面
- **高光层**：底色升两阶，点状或线状，集中在金属边缘和受光面

### 七、赛璐璐风格表现要点

#### 7.1 线稿

- 线条粗细分明：外轮廓线最粗（2-3px），铠甲分割线中等（1.5px），面部细节线最细（1px）
- 线条颜色不统一：铠甲外轮廓用深蓝灰线（#2A3540），皮肤用暖棕线（#8B6040），荆棘用纯黑线
- 关键结构处（肩甲尖角、盾牌边缘、伤疤）线条加粗强调
- 面部线条刻意柔于铠甲线条，体现「铁甲之下的少女面容」这一核心反差

#### 7.2 上色

- 所有色块边缘清晰，不做柔边渐变
- 阴影采用硬边切割，形状为几何多边形，方向统一从右下至左上
- 金属表面高光为细长条状，非渐变，直接用浅色色块覆盖
- 面部赛璐璐阴影集中在刘海下方和鼻梁侧面，用一块三角形色块表现
- 皮肤上色偏白，与铠甲的深色形成强烈明度对比

#### 7.3 特效层

- **嘲讽状态**：身体周围浮现荆棘光环，用红色线框+半透明红色填充表现
- **减伤状态**：铠甲表面浮现一层半透明的绿色光膜，用赛璐璐方式处理为边缘清晰的色块叠加
- **队长加成状态**：脚下扩散出金色光环，用同心圆线稿+金色半透明填充

### 八、表情与姿态设计

#### 8.1 默认立绘姿态

- 正面微侧身（15度角），左手持「壁垒」巨盾竖立于身前，右拳握紧垂于体侧
- 重心微微前倾，呈随时准备冲锋的姿态
- 目光直视前方，眉头微皱，嘴角紧抿
- 荆棘从肩甲缝隙向生长，有一根荆棘延伸至盾面
- 巨盾几乎遮住她半边身体，仅露出上半张冷峻的面孔和一缕银白色的短发

#### 8.2 表情变化

| 状态 | 表情描述 |
|------|----------|
| 默认 | 严肃沉默，眉头微皱，冷峻的面容如冰 |
| 受伤（HP<50%） | 眉头紧锁，咬牙，荆棘蔓延至面部，左眼被荆棘遮住一半。白皙的脸上浮现汗珠，但眼神依旧不屈 |
| 嘲讽技能 | 怒目圆睁，瞳孔金光大盛，嘴角微微上扬露出战意——极罕见的锋利笑容 |
| 队长加成 | 表情略微柔和，目光偏向身后的队友，嘴角几乎不可察觉地弯起，是那种「我护着你们」的安心感 |
| 升星满级（6星） | 铠甲褪去，露出布满荆棘纹路的上半身，肩背可见旧伤交织的痕迹。眼神平静如水，短发在风中微扬，有一种卸下重担后的少女感 |

### 九、标志性画面

**概念场景描述**

「城墙已塌，身后是受伤的同伴。她将巨盾重重插入地面，银白短发在烟尘中飞扬。荆棘从铠甲裂缝中疯狂生长，攀上她白皙的脖颈与面颊，编织成第二道城墙。箭雨、魔法、刀剑——全部打在她身上。她一步未退。」

> 画面构图：低角度仰视，荆铁位于画面中央偏左，巨盾竖于右侧。背景是漫天飞来的攻击特效（箭矢、火球），全部被盾面和荆棘挡住。她的铠甲已碎裂大半，荆棘填补了所有缺口，藤蔓攀上了她半边脸庞。左眼从荆棘缝隙中透出金光，嘴角带着一丝不易察觉的微笑——那是对身后同伴「我没事」的无声承诺。

## 05 · 磐姬「先锋」

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 以东方山岳要塞美学为基底，融合玉石矿物元素与美少女的沉静气质。赛璐璐上色强调石材质感的块面切割、苔藓纹理的平面装饰性，以及玉石化过程中的光泽渐变。人物造型为矮壮结实的要塞少女，浑圆厚重的石甲与她柔和圆润的面庞形成「坚不可摧的温柔」这一核心反差。

### 一、角色基本信息

| 项目 | 内容 |
|------|------|
| 角色名 | 磐姬（Pán Jī） |
| 职业 | 先锋 |
| 定位 | 前排坦克 / 伤害分摊 / 反震控场 |
| 身高 | 163cm |
| 体型 | 结实圆润，肩宽腰厚，四肢粗短有力。不属于纤细型，而是「像一块墩实的岩石」的体态，穿衣显壮但脱下甲后皮肤意外地白皙细腻 |
| 年龄外观 | 20岁左右 |
| 性别 | 女 |
| 基础HP | 150 |
| 基础ATK | 8 |

### 二、角色背景故事

磐姬出身于大陆西南的「磐石城」——一座依附于巨岩山体开凿的要塞都市。磐石城人世代以石工和守城为业，城中每一名女子都要学习「石化心法」：将灵力注入骨骼与皮肤，使肉体在受击时逐渐矿物化，化为坚不可摧的玉石壁垒。

磐姬是磐石城历代城主之女，也是石化心法最强的一人。在磐石城遭遇围城战时，她独自镇守城门七日七夜。每当敌军的攻击落在她身上，她的皮肤便多积一层翡翠色的「磐石」——不是逐渐玉石化，而是每一击都在体表结晶出一层新的玉石鳞甲。七日之后，她体表已叠出数十层磐石，每一击不仅无法伤她，反震之力将攻城器械崩碎。

她性格沉静温厚，说话慢条斯理，像石头落地的节奏。不善于拒绝别人，对任何请求都会点头答应，然后用行动默默完成。她将磐石蓄能视为「礼物」而非「诅咒」——每一层磐石都是保护同伴的勋章，而反震之力则是城墙对攻城者的回敬。口头禅是：「别急。有我在这里。」

> **美少女特征要点**：属于「温柔巨石」型角色——结实圆润的体态、圆润柔和的面庞、温吞慢热的性格，是四人中最具「让人安心」气质的角色。她的美不在于纤细或锋利，而在于那种「任凭风吹雨打也纹丝不动」的沉稳与温暖。玉石鳞片使她白皙的皮肤上浮现翡翠色的矿物结晶，石与肤的交融构成一种「越战越坚的活玉」的独特美感——区别于荆铁「越残血越硬」的凄烈，磐姬是「越挨打越从容」的沉稳。

### 三、外貌设计

#### 3.1 面部特征

- **脸型**：圆润的鹅蛋脸，下颌线柔和，面部有少女的丰满感。不属于精致小巧型，而是「让人觉得踏实」的圆脸庞，带着一点婴儿肥

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 以日式传统人偶美学为基底，融合哥特式傀儡元素与美少女的精致面庞。赛璐璐上色强调瓷器般的肤质、木质关节的机械感，以及和风纹样的平面装饰性。她是「美到令人不安」的人偶少女——太过完美的对称面容、太过空洞的红色眼眸、太过宁静的微笑。

### 二、角色背景故事

「椿偶」原本是暗杀组织「落椿流」用于训练新人的活体木桩——一具被施加了禁术的战斗人偶。她由千年椿木雕刻而成，以少女为原型，关节处嵌有咒术铁环，可以模拟人类的战斗动作。新人刺客们反复对她进行刺杀训练，而她也在无尽的被击打中，逐渐产生了自我意识。

她不理解疼痛，却能感受到每一次刀刃切入身体时，某种「渴望」在生长——不是对生存的渴望，而是对「攻击」本身的渴望。某一天，她在训练中第一次主动挥刀，斩杀了面前的训练生。从此，「训练用的人偶少女」成为了最危险的刺客。

她的口头禅是：「疼痛……是什么？教教我。」

> **美少女特征要点**：属于「诡异美人」型角色——外表是无害的精致少女，黑发红瞳、瓷白肌肤、樱桃小嘴的微笑，却透着令人背脊发凉的空洞。她的美在于「不完整感」：球体关节的接缝、胸口宝石的裂纹、背后无形的操控线，都在暗示这个美丽的少女不是人。她是四人中体型最小、面容最精致、杀伤力却最高的一个。

### 二、角色背景故事

夜鸩出身于大陆南境的「鸩毒谷」——一片被千年毒雾笼罩的沼泽密林。谷中生长着世间最致命的毒草「夜鸩花」，其花汁一滴便可毒杀一匹战马。谷中居民世代以毒为伴，血液中天然含有剧毒，被称为「行走的毒药」。

夜鸩是谷中最后一任「毒母」的独女，自幼被用夜鸩花汁浸泡淬炼，使她的血液成为世间最烈的毒药。她的每一次呼吸都带着淡淡的花香，却足以让常人头晕目眩；她的血液沾上伤口，便是致命的毒杀。

她离开鸩毒谷的原因很简单——「谷中已经没有比我更毒的东西了」。她想寻找能让自己感受到「痛」的对手，因为毒母告诉她：只有比你更强的毒，才能让你感受到疼痛。她不理解恐惧，不理解死亡，只理解「毒」与「被毒」之间的关系。

她的口头禅是：「靠近我的话……会死哦？虽然你已经在笑了。」

> **美少女特征要点**：属于「妖冶毒花」型角色——外表是妖冶美丽的少女，深紫长发、幽绿毒瞳、苍白的皮肤上浮现青色毒脉纹路，嘴角永远挂着暧昧的微笑。她的美在于「危险感」：指尖的荧光毒液、皮肤下隐约可见的青色脉络、以及那双看什么都像在评估「能不能毒死」的幽绿眼睛。她是四人中最具「致命吸引力」的一个，美丽与危险在她身上不可分割。

> **风格定位：日式赛璐璐风格（Cell-shading）**

### 二、角色背景故事

蜃景出身于大陆西境的「黄沙海」——一片无边无际的沙漠，其中栖息着传说中的灵兽「蜃」。蜃能吐出蜃气制造海市蜃楼，将虚幻的景象投射到现实之中。沙漠游牧部族「风驼族」世代追寻蜃的踪迹，从中学习蜃气的幻术。

蜃景是风驼族中最出色的斥候，被称为「沙海蜃影」——她能在漫天沙暴中精准定位方向，更能以蜃气编织幻象，让敌人看到根本不存在的景象。在一次深入蜃巢的任务中，她的右眼被蜃气侵蚀，从此那只眼睛变成了蜃的瞳色——「蜃之眼」，能将真实与虚幻交织，甚至能将对方手中的底牌替换为虚假的蜃影。

她与影翎同为斥候，但风格截然不同：影翎是「看穿一切」的斥候，蜃景是「让对方看错一切」的斥候。她不窃取情报，而是制造欺骗——在沙漠里，你看到的一切都是她让你看到的。

失去正常视觉后，她变得洒脱而从容，用一句「该看到的自然能看到」来回应一切质疑。她爱笑，笑容像沙漠中突然出现的绿洲——让人惊喜又短暂。没有人见过她真正慌张的样子。口头禅是：「在沙漠里，你看到的都是假的——除了我。」

> **美少女特征要点**：属于「飒爽幻影」型角色——利落短发、异色瞳、薄纱覆面，是四人中最具「沙漠侠女」气质的角色。她的美在于那种「看得见抓不住」的虚幻感：沙金色碎发在风中飞扬、一只天蓝一只沙金的异色瞳、永远半遮面的薄纱。她笑容飒爽却带着一丝距离感，像沙漠中的海市蜃楼——你知道她就在那里，却永远触碰不到。区别于影翎「看穿一切的鸦之眼」，蜃景是「让对方看错一切的蜃之眼」——一个窃取真实，一个制造虚假。

### 二、角色背景故事

神无月出生在大陆中央的「无月神社」，是世代侍奉月神「ツキヨミ」的巫女一族后裔。她出生那夜恰逢「神无月」——十月，诸神离去之月，天穹无月。族中长老说她是「神弃之子」，命带孤煞。

然而事实恰恰相反。她并非被月神抛弃，而是被月神选中——作为容器。她的身体中封印着月神的一缕分魂，这使她拥有削弱他人力量的能力：以月蚀之力侵蚀对方的攻击力。代价是，她自身的攻击力同样微弱——月神之力用于「消减」而非「增长」。

她性情温和但疏离，说话轻声细语，仿佛怕惊扰了体内的神魂。她从不与人亲近，因为她的力量会无差别地削弱身边所有人的活力。这让她习惯了孤独——美丽，却触碰不到。

口头禅是：「靠近我的话……会变弱的哦。」

> **美少女特征要点**：属于「清冷疏离」型角色——银发紫瞳、和风巫女装束、月环虚影，是最具「正统美少女」外形的角色。但她的美带着悲剧性：她越是美丽，越是不能被触碰；她越是温柔，越是不敢靠近任何人。她是四人中外表最柔弱、气质最空灵的一个。月环、符纸、银发飘扬——她的每个元素都在营造一种「随时会化为月光消散」的虚幻美。

### 二、角色背景故事

曦和出生在大陆东方的「曦和神殿」——一座建于山巅、终年沐浴在日光中的神殿。神殿世代侍奉日神「曦和」，以观测日轮轨迹、守护光之秩序为使命。曦和神殿的巫女们被称为「日轮侍者」，拥有以日光灼烧万物的力量。

曦和出生那日恰逢「日全蚀」——太阳被完全遮蔽的时刻。神殿长老认为她是「蚀命之女」，命带灾祸。然而事实恰恰相反：她并非被日神抛弃，而是被日神选中——作为容器。她的身体中封印着日神的一缕分魂，这使她拥有以日轮之力灼烧万物的能力：被她标记的目标将持续被日光灼烧，每回合承受灼伤。代价是，她自身的攻击力同样微弱——日神之力用于「灼烧」而非「增长」，她是进攻型祭司而非辅助型。

她与神无月同为祭司，但风格截然相反：神无月以月蚀之力「削弱」对方攻击力（降攻），曦和以日轮之力「灼烧」对方生命值（持续伤害）。一个月蚀消减力量，一个日轮焚毁生命。

她性情热烈而疏离，说话声如铜铃清越，带着不容置疑的气势。她从不与人亲近——不是因为冷漠，而是因为她的力量会无差别地灼烧身边所有人的活力。靠近她的人会感到精力被抽走，如同站在烈日下太久。这让她习惯了独行——耀眼，却无人能伴。

口头禅是：「不要离我太近。光芒……也会灼伤人。」

> **美少女特征要点**：属于「灼热疏离」型角色——金红长发、琥珀瞳、日轮神殿装束、日环虚影，是最具「正统英气美少女」外形的角色。但她的美带着悲剧性：她越是耀眼，越是不敢被靠近；她越是热烈，越是不敢对任何人展露温度。她是四人中外表最夺目、气质最热烈的一个，却也是最孤独的一个。日环、符纸、金红长发飞扬——她的每个元素都在营造一种「美到灼眼却触碰不得」的炽烈美。与神无月的冷月相对，她是那轮灼日——一个月蚀消减力量（降攻自愈），一个日轮焚毁生命（灼烧持续伤害），同为祭司却攻守倒置。

- **队长加成状态**：友方使用技能时，随机敌方浮现金色灼烧纹路
- **6星觉醒**：背后日环碎裂重组为星辰图案，衣袂飞舞更加剧烈，金红长发在碎裂的日光中飞舞

### 八、表情与姿态设计

#### 8.1 默认立绘姿态

- 正面站立，身体微微侧向右侧，双手交叠于胸前持「日蚀」神杖竖立
- 头微微昂起，目光从上方明亮地注视观者，嘴角带着英武的微扬
- 日纱随微风向右飘扬，飘带和金红长发向同方向飘动
- 背后日轮缓缓旋转，周围符纸飘浮
- 整体呈「静止中的流动」——少女安静但衣袂飘动。巨大的日轮虚影在她身后缓缓旋转，金红长发如焰瀑垂落

#### 8.2 表情变化

| 状态 | 表情描述 |
|------|----------|
| 默认 | 微微昂首，嘴角微扬，琥珀杏眼明亮但疏离。如日轮般夺目而不可近 |
| 施加灼烧技能 | 抬头直视目标，瞳孔中倒映出灼烧火焰纹，表情凌厉。热烈的少女一瞬间变得如日神般不可逼视——她在焚毁对方的生命 |
| 双向灼烧技能 | 闭眼，眉头蹙起，嘴角下压——使用此技能时自身也会被灼烧。痛苦的表情在明媚的面庞上格外令人心痛——她在用自己的生命换取对方的毁灭 |
| 被动灼烧结算 | 表情不变，但嘴角微微上扬一瞬——每回合结束时灼烧在目标身上闪烁，如同远处传来的一记无声的日鼓 |
| 6星觉醒 | 日环碎裂，睁眼时瞳孔变为金色星辰纹，表情从疏离变为释然微笑。金红长发在碎裂的日光中飞舞——终于可以靠近别人了 |

### 九、标志性画面

**概念场景描述**

「正午的烈日下，她独自站在神殿的鸟居前。金红长发如焰瀑垂落，背后巨大的日轮缓缓旋转，将金色的光辉洒落满地。她抬起神杖，杖顶日轮映照着天上的太阳——两轮日轮遥遥相对。敌人冲来，她轻轻一挥杖，赤红的日蚀纹便爬上了对方的武器，刀剑变得沉重如山，力量如被烈日蒸干。少女声如铜铃：'我说了……靠近我会灼伤的。'——她的语气不像警告，更像一句带着歉意的叹息。」

> 画面构图：正面构图，曦和位于画面正中央，持杖而立。背后巨大的日轮虚影占据画面上半部分，金色光辉从日环散射形成放射状光线（用赛璐璐方式的金色线条+半透明色块表现）。地面铺满日光，她的倒影在地面日光中呈现为另一个姿态（暗示日神分魂）。飘浮的符纸环绕在她身周，经文微微发光。日纱和金红长发向左侧飘动，右下角是冲来的敌人被日蚀纹灼烧武器的局部画面。整体色调为金色+赤红，是四个角色中色彩最灼热的一张。少女挺拔的身形立于巨大的日轮之下，像一朵日光凝成的花。
