> **文档定位：正式角色叙事与概念美术基准。** 玩法数值和技能结算以 `docs/英雄类型/角色1.md` 与运行时英雄资源为准；本文的复杂服饰和特效用于高精度概念图，落地 `128×160` 像素战斗立绘时必须按安全区做取舍。

## ── 先锋「荆铁」 ──

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 线条清晰锐利，色块分明，阴影采用硬边切割，高光集中于金属边缘与瞳孔，整体呈现日式动画般的平面化质感。人物造型为高挑挺拔的骑士少女，硬朗铠甲与少女身形形成鲜明反差。

## 二、角色背景故事

荆铁曾是北境边塞「铁壁军团」中最年轻的副将，以一人之力镇守关门三日不死，被士兵们称为「不倒的铁壁姬」。在一次惨烈的守城战中，她主动替战友挡下了致命的魔法轰击，全身被荆棘魔法侵蚀。此后她的铠甲与血肉共生，荆棘从铠甲缝隙中生长，成为一种活体护甲——越是受伤，荆棘越是茂密，防御反而越强。

她沉默寡言，习惯站在最前方承受一切，面容常年冷峻，却会在队友受伤时默默将自己的披风盖在对方身上。不善于表达感情，所有关心都化作行动。口头禅是：「站在我身后。」

> **美少女特征要点**：属于「可靠大姐姐」型角色——高挑、冷峻、寡言，但骨子里极重感情。她的美不在于柔媚，而在于那种「即使遍体鳞伤也绝不后退一步」的凛然英姿。荆棘从少女白皙的皮肤上生长，铁与花的共生构成独特的暴力美学。

## 三、外貌设计

### 3.1 面部特征

- **脸型**：修长的鹅蛋脸，下颌线利落分明，轮廓介于少女的柔和与武人的刚毅之间
- **眼睛**：窄长凤眼，微微上挑，虹膜为暗金色（#C8A038），瞳孔为竖线状，战斗时会微微发光。赛璐璐处理时采用双色瞳孔——外圈深金、内圈亮金高光点。眼尾微翘，冷冽中透出一丝英气
- **眉毛**：英气剑眉，略微偏粗，左眉有一道斜向伤疤，伤痕切断了眉形
- **鼻子**：高挺鼻梁，鼻梁窄而精致
- **嘴唇**：薄唇，唇色偏淡，嘴角微微下压，表情常年严肃。偶尔在队友看不到的角度会露出一丝极浅的笑意
- **伤疤**：左脸颊至颧骨处有一道显眼的战伤疤痕，呈锯齿状（荆棘划痕）。伤痕横过白皙的面庞，构成一种「带着伤疤也很美」的硬朗吸引力

### 3.2 发型发色

- **发色**：钢铁灰白（#B8B8C0），发根处偏深铁灰色，发梢渐变为银白
- **发型**：齐耳短发的利落造型，后颈处发尾微翘。头顶前方有一撮向上翘起的呆毛（赛璐璐风格中作为角色辨识点，用硬边色块表现）。左侧鬓角留一束较长碎发垂至脸颊，恰好遮住部分伤疤
- **质感表现**：发丝不细分，用大色块铺底色，留出1-2道银白色高光条。短发造型凸显她干练利落的性格

### 3.3 体型身姿

- 高挑匀称的少女体型，肩线平直而略宽（但不失女性线条），腰背紧实，双腿修长
- 站姿微微前倾，重心下沉，双手习惯性握拳垂于身侧
- 宽厚的肩甲使整体轮廓呈梯形，但铠甲缝隙处露出的肢体线条依然纤细
- 赛璐璐表现时强调肩部、胸甲、护腿的几何块面感，同时在铠甲间隙用细线勾勒少女的肢体轮廓，形成「重甲之下是纤细身躯」的对比

## 四、服装设计

### 4.1 铠甲主体

- **胸甲**：厚重的板甲胸铠，正面铸有荆棘缠绕盾牌的纹章。胸甲表面有明显的锤打纹理，用赛璐璐方式处理为两层色阶——基底钢铁蓝灰（#5C6B7A），高光面为浅银灰（#A8B5C0）。胸甲成型贴合女性躯干，腰部收窄
- **肩甲**：左右不对称设计。左肩为巨型兽首肩甲（狮鹫头造型），右肩为常规板甲。肩甲边缘有荆棘纹饰向外延伸。左肩甲略显庞大，与少女的肩线形成夸张比例，强化「以小身躯扛重甲」的视觉冲击
- **臂甲**：前臂覆有层叠式板甲护臂，关节处可见锁子链环连接。臂甲与裸露的上臂形成对比——金属的粗粝与少女手臂的白皙
- **腿甲**：大腿至膝盖为全覆式板甲，小腿为胫甲+锁甲裙摆。大腿铠甲与大腿之间的缝隙露出深绯色战袍衬里和一小段白皙皮肤

### 4.2 内衬衣物

- 铠甲内穿深绯红色（#8B2D2D）的厚织物战袍，从铠甲缝隙处露出。战袍为立领长袖款式，领口微微敞开露出锁骨
- 战袍下摆呈不规则撕裂状，边缘有焦痕，从腿甲下方露出如短裙般的碎裂布片
- 腰间系有宽大的黑色皮带，皮扣为荆棘花纹金属扣。皮带勒紧腰线，强调她窄而紧实的腰身

### 4.3 荆棘共生元素（核心视觉特征）

- 从铠甲的缝隙（颈部、肩关节、腰侧）生长出黑铁色的荆棘藤蔓，藤蔓缠绕在少女白皙的皮肤上，形成「花与铁」的视觉张力
- 荆棘上偶有暗红色小花苞，代表她的生命力——HP越低荆棘越茂密（可作为受伤状态的视觉变化）
- 赛璐璐处理：荆棘用纯黑勾线，填充深墨绿色（#2A3A2A），尖刺处点白色高光。荆棘爬过少女皮肤的部分，用极细的暗红线描表现藤蔓与皮肤的交界

## 五、配饰与道具

### 5.1 武器——「壁垒」巨盾

- **形态**：人高的塔盾，盾面宽厚，顶部呈V形缺口。盾牌竖立时几乎可以遮住她的半个身躯，形成「娇小少女+巨盾」的经典反差
- **材质**：黑铁铸造，盾面刻有荆棘缠绕城墙的浮雕
- **细节**：盾牌背面嵌有一面小镜（用于反射光线信号），盾缘包铜
- **赛璐璐表现**：盾面用三段色阶表现金属质感——暗面（#3A4550）、中间调（#6B7B8A）、高光面（#C0CCD8），边缘锐利切割

### 5.2 其他配饰

- **颈部**：戴有一条粗铁链项链，坠子是一枚残破的军徽（铁壁军团标志）。铁链衬托在修长的脖颈上，粗粝金属与白皙皮肤形成对比
- **右手**：无名指上有一枚黑色铁戒，戒面刻有"守"字
- **披风**：无长披风（避免遮挡铠甲设计），取而代之的是腰后挂有一截断裂的战旗旗杆，旗面已残破不堪。战旗旗面偶尔会被她取下，披在受伤的队友身上

### 6.2 赛璐璐色阶规则

每个色彩区域严格分为三层色阶：
- **底色层**：主色调，占面积最大
- **阴影层**：底色降两阶，硬边切割，集中在背光面
- **高光层**：底色升两阶，点状或线状，集中在金属边缘和受光面

## 七、赛璐璐风格表现要点

### 7.1 线稿

- 线条粗细分明：外轮廓线最粗（2-3px），铠甲分割线中等（1.5px），面部细节线最细（1px）
- 线条颜色不统一：铠甲外轮廓用深蓝灰线（#2A3540），皮肤用暖棕线（#8B6040），荆棘用纯黑线
- 关键结构处（肩甲尖角、盾牌边缘、伤疤）线条加粗强调
- 面部线条刻意柔于铠甲线条，体现「铁甲之下的少女面容」这一核心反差

### 7.2 上色

- 所有色块边缘清晰，不做柔边渐变
- 阴影采用硬边切割，形状为几何多边形，方向统一从右下至左上
- 金属表面高光为细长条状，非渐变，直接用浅色色块覆盖
- 面部赛璐璐阴影集中在刘海下方和鼻梁侧面，用一块三角形色块表现
- 皮肤上色偏白，与铠甲的深色形成强烈明度对比

### 7.3 特效层

- **嘲讽技能激活时**：身体周围浮现荆棘光环，用红色线框+半透明红色填充表现
- **减伤状态时**：铠甲表面浮现一层半透明的绿色光膜，用赛璐璐方式处理为边缘清晰的色块叠加
- **队长加成时**：脚下扩散出金色光环，用同心圆线稿+金色半透明填充

## 八、表情与姿态设计

### 8.1 默认立绘姿态

- 正面微侧身（15度角），左手持「壁垒」巨盾竖立于身前，右拳握紧垂于体侧
- 重心微微前倾，呈随时准备冲锋的姿态
- 目光直视前方，眉头微皱，嘴角紧抿
- 荆棘从肩甲缝隙向生长，有一根荆棘延伸至盾面
- 巨盾几乎遮住她半边身体，仅露出上半张冷峻的面孔和一缕银白色的短发

### 8.2 表情变化

| 状态 | 表情描述 |
|------|----------|
| 默认 | 严肃沉默，眉头微皱，冷峻的面容如冰 |
| 受伤（HP<50%）| 眉头紧锁，咬牙，荆棘蔓延至面部，左眼被荆棘遮住一半。白皙的脸上浮现汗珠，但眼神依旧不屈 |
| 嘲讽技能 | 怒目圆睁，瞳孔金光大盛，嘴角微微上扬露出战意——极罕见的锋利笑容 |
| 队长加成 | 表情略微柔和，目光偏向身后的队友，嘴角几乎不可察觉地弯起，是那种「我护着你们」的安心感 |
| 升星满级（6星）| 铠甲褪去，露出布满荆棘纹路的上半身，肩背可见旧伤交织的痕迹。眼神平静如水，短发在风中微扬，有一种卸下重担后的少女感 |

## 九、设计元素与游戏机制关联

| 游戏机制 | 对应设计元素 |
|----------|-------------|
| HP=150（全角色最高） | 虽为少女体型，铠甲最厚重，加上荆棘共生系统，视觉上传达「难以击倒」的感觉 |
| ATK=10（偏低） | 武器为盾而非刃，攻击性弱化，防御感强化。她的力量主要用于守护而非追求爆发伤害 |
| 分段减伤（越残血越硬） | 荆棘共生系统——受伤越重荆棘越密，视觉上随HP降低而「长出」更多防御。少女白皙皮肤上荆棘越生越多，有一种凄烈的美感 |
| 嘲讽技能（替队友承伤） | 巨盾+前倾站姿，随时准备挡在前方的视觉语言。她的美丽身体成为队友的城墙 |
| 队长加成（全队加临时HP） | 军团副将背景+残破军旗，象征守护团队的使命。作为「大姐姐」角色的天然保护欲 |
| 6星失去职业 | 铠甲与荆棘融为一体的最终形态，少女卸下甲胄后展露伤痕累累的身体，脱离「先锋」身份的视觉蜕变——从「铁壁」回归「少女」 |

## 十、标志性画面

### 概念场景描述

「城墙已塌，身后是受伤的同伴。她将巨盾重重插入地面，银白短发在烟尘中飞扬。荆棘从铠甲裂缝中疯狂生长，攀上她白皙的脖颈与面颊，编织成第二道城墙。箭雨、魔法、刀剑——全部打在她身上。她一步未退。」

> 画面构图：低角度仰视，荆铁位于画面中央偏左，巨盾竖于右侧。背景是漫天飞来的攻击特效（箭矢、火球），全部被盾面和荆棘挡住。她的铠甲已碎裂大半，荆棘填补了所有缺口，藤蔓攀上了她半边脸庞。左眼从荆棘缝隙中透出金光，嘴角带着一丝不易察觉的微笑——那是对身后同伴「我没事」的无声承诺。
