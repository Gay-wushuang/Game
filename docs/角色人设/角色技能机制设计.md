# 角色技能机制设计文档（美少女版）

> 本文档详细定义了8名角色的技能机制、数值设定、升星强化逻辑及职业对位关系，是战斗系统设计与平衡性调整的核心依据。

---

## 第一部分：游戏机制术语说明

### HP（生命值）
- **定义**：角色的生存能力数值，代表角色能够承受的伤害总量。HP归零则角色阵亡，退出战斗。
- **归零效果**：角色从战场上移除，不再参与任何行动、承受伤害或触发效果。
- **与角色定位关系**：先锋职业HP最高（150），承担前排承伤职责；刺客与祭司HP较低（80），属于脆皮输出/辅助；斥候HP居中（100），平衡生存与机动。

### ATK（攻击力）
- **定义**：角色普通攻击造成的基础伤害值。
- **伤害计算**：基础伤害 = ATK - 目标减伤（固定减伤优先扣除，剩余伤害再计算百分比减伤）。护盾优先于减伤吸收伤害。
- **基础值范围**：刺客最高（15），斥候居中（10），先锋与祭司最低（8）。

### 被动技能
- **定义**：无需主动释放、在满足特定条件时自动触发的技能效果。
- **触发条件**：包括回合开始/结束时、受到攻击时、攻击命中时、使用技能后等。
- **与主动技能的区别**：被动技能不消耗行动力、没有冷却时间、不可被封印；主动技能需要手动释放、消耗资源、有CD限制。

### 主动技能
- **定义**：玩家主动选择释放的技能，通常需要消耗行动力并有冷却时间。
- **消耗**：消耗一定数量的行动力（AP），部分技能有额外代价（如自伤、跳过下回合等）。
- **冷却概念**：技能释放后需要等待若干回合才能再次使用，冷却回合数记为CD。

### 队长加成
- **定义**：当角色担任队长时，为全队提供的常驻增益效果。
- **触发条件**：该角色被设为队长时，战斗全程生效。
- **全队效果**：对己方所有角色生效，包括队长自身。

### 职业定位

#### 先锋
- **核心定位**：前排坦克 / 伤害吸收 / 团队守护
- **职责**：站在队伍最前方承受敌方攻击，通过嘲讽、减伤、护盾、分摊等机制保护队友。
- **特点**：HP最高（150），ATK最低（8），以生存能力和团队防护为核心价值。

#### 刺客
- **核心定位**：高攻脆皮 / 爆发输出 / 持续削弱
- **职责**：对敌方造成高额伤害，通过爆发或持续伤害快速削减敌方HP。
- **特点**：ATK最高（15），HP最低（80），以高输出换取低生存。

#### 斥候
- **核心定位**：信息干扰 / 行动力操控 / 手牌破坏
- **职责**：通过信息获取、行动力增减、手牌干扰等方式掌控战斗节奏。
- **特点**：HP与ATK均为中等（100/10），以资源操控和信息差为核心价值。

#### 祭司
- **核心定位**：辅助控场 / 持续效果 / 双向影响
- **职责**：通过减益、增益、持续伤害或恢复等方式影响战场局势。
- **特点**：HP较低（80），ATK较低（8），但拥有双主动技能，战术选择丰富。

### DOT（持续伤害/伤害持续生效）
- **定义**：Damage Over Time，施加在目标身上的持续伤害效果，在每回合的特定时机结算伤害。
- **类型**：
  - **毒伤（鸩毒）**：夜鸩的核心机制，每层每回合造成固定伤害，同时降低目标ATK，可多层叠加。
  - **灼烧**：曦和的核心机制，每回合造成固定伤害，持续若干回合，可与条件降攻联动。
- **结算时机**：回合开始时（毒伤）或回合结束时（灼烧）结算，具体以技能描述为准。

### Debuff（减益效果）
- **定义**：施加在敌方角色身上的负面效果，削弱其战斗能力。
- **类型**：
  - **降ATK**：降低目标的攻击力数值。
  - **封印**：使目标的某张锦囊牌在本局内无法使用（永久封印）或暂时无法使用。
  - **行动力消耗增加**：使对方使用锦囊牌时需要消耗更多行动力。
  - **毒伤DOT**：同时造成持续伤害和降ATK的复合减益。
- **持续时间**：不同Debuff持续时间不同，有的持续到战斗结束（如永久封印），有的持续若干回合（如灼烧3回合），有的可叠加层数（如鸩毒最多3/5层）。

### Buff（增益效果）
- **定义**：施加在己方角色身上的正面效果，增强其战斗能力。
- **类型**：
  - **攻击力提升**：临时或常驻增加ATK数值。
  - **行动力增加**：每回合获得额外行动力。
  - **免行动力**：使用锦囊牌时不消耗行动力。
  - **减伤提升**：增加固定或百分比减伤。
  - **临时HP**：获得额外的生命值上限。
  - **冷却减少**：技能冷却时间缩短。

### 减伤机制

#### 固定减伤
- **定义**：受到伤害时，先扣除固定数值的减伤量。
- **特点**：对低额多次攻击效果极佳，对高额单次攻击效果有限。代表：磐姬的磐石层数（每层固定减伤15）。

#### 百分比减伤
- **定义**：受到伤害时，按百分比削减伤害。
- **特点**：对高额单次攻击效果极佳，对低额多次攻击效果有限。代表：荆铁的分段减伤（越残血减伤百分比越高）。

#### 叠加关系
- 先计算固定减伤，再计算百分比减伤。即：最终伤害 = (基础伤害 - 固定减伤) × (1 - 百分比减伤)。

### 护盾
- **定义**：一种可以吸收伤害的临时保护层，在角色HP之外独立计算。
- **与减伤的叠加关系**：护盾优先吸收伤害，减伤在护盾吸收后仍对剩余伤害生效（如有）。即：先扣护盾，护盾不足时扣除HP，扣除HP部分计算减伤。

### 嘲讽
- **定义**：强制敌方攻击自己的技能效果。
- **强制攻击目标机制**：嘲讽激活期间，敌方所有普通攻击和指向性技能必须以嘲讽目标为目标，无法选择其他角色。范围伤害不受嘲讽影响。

### 反震/反伤
- **定义**：受到攻击时，将部分伤害反弹给攻击者的效果。
- **触发条件**：每次受到攻击（被命中）时触发，反弹固定数值或百分比的伤害。
- 代表：磐姬的磐石反震（每层反震10点伤害）。

### 伤害分摊
- **定义**：将原本由单个角色承受的伤害，由多个角色共同分担的机制。
- **多人分担伤害的机制**：例如磐姬的玉石结界，友方受到的伤害50%由磐姬分摊承受，即目标只承受50%伤害，磐姬承受另外50%。

### 行动力
- **定义**：每回合可用于执行行动的资源点数，简称AP。
- **消耗方式**：普通攻击、使用主动技能、打出锦囊牌均消耗行动力。
- **与技能释放的关系**：技能有各自的行动力消耗，行动力不足时无法释放。

### 手牌/锦囊牌
- **定义**：战斗中可使用的策略卡牌，即锦囊牌，存放在手牌区。
- **操作说明**：
  - **弃牌**：将手牌中的锦囊牌弃置到弃牌堆，被弃置的牌本回合无法使用。
  - **封印**：使某张锦囊牌在本局战斗中永久无法使用，被封印的牌从手牌中移除。
  - **替换**：将对方手牌中的某张牌替换为虚假的"蜃影"，打出时无效但消耗行动力。

### 冷却时间（CD）
- **定义**：技能释放后需要等待的回合数，等待期间无法再次使用该技能。
- **减少冷却的效果**：通过技能或队长加成缩短冷却时间，使技能可以更快地再次使用。例如神无月的队长加成"冷却-1"。

### 升星系统
- **定义**：角色从1星到6星的成长系统，每个星级解锁或强化特定机制。
- **1-6星机制强化逻辑**：
  - 1星：基础机制小幅强化（如武器纹路、数值微调）
  - 2星：核心机制上限提升（如最大层数+2、被动可视化常驻）
  - 3星：核心效果数值强化（如减伤提升、降攻效果增强）
  - 4星：技能范围/威力升级（如双扇增大、肩甲升级）
  - 5星：质变级强化（如代价降低、封印数量+1）
  - 6星：觉醒形态，失去职业身份，获得终极形态

### 6星觉醒/失去职业
- **定义**：角色突破到6星时的终极形态，脱离原有职业身份束缚，获得全新姿态。
- **概念**：角色从职业赋予的身份中解脱，回归最本真的自我形态。视觉上表现为铠甲/束缚的碎裂/褪去，能力上达到巅峰。
- 例如：荆铁从"铁壁先锋"回归"荆棘少女"，椿偶从"刺客人偶"回归"有感情的少女"。

## 第三部分：各角色详细机制设计

---

### 先锋组

#### 01. 荆铁

**1. 角色定位说明**
- **核心定位**：前排百分比减伤坦克，越残血越硬，以嘲讽和临时HP守护全队。
- **设计思路**：以"荆棘共生"为核心概念——受伤越重，荆棘越密，防御越强。区别于磐姬的固定减伤路线，荆铁走百分比减伤路线，对高额伤害的抗性更强。嘲讽机制使她成为团队的"人形城墙"，替队友承受所有指向性攻击。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 150 | 全角色最高 |
| ATK | 8 | 全角色最低 |

**3. 被动技能：荆棘共生（分段百分比减伤）**
- **名称**：荆棘共生
- **效果描述**：HP越低，受到的伤害减免百分比越高。荆棘铠甲与血肉共生，受伤越重，防御越强。
- **触发条件**：受到伤害时自动触发，常驻被动。
- **机制细节**：
  - HP > 75%：减伤20%
  - HP 50%~75%：减伤35%
  - HP 25%~50%：减伤50%
  - HP < 25%：减伤65%
  - 属于百分比减伤，在固定减伤之后计算。
  - 视觉表现：HP降低时，少女皮肤上的荆棘藤蔓越发茂密。

**4. 主动技能：荆棘嘲讽**
- **名称**：荆棘嘲讽
- **效果描述**：强制敌方所有指向性攻击以自己为目标，持续1回合。期间自身获得荆棘光环，反震少量伤害。
- **消耗/代价**：消耗2点行动力，CD 3回合。
- **机制细节**：
  - 嘲讽期间，敌方普通攻击和单体技能只能选择荆铁为目标。
  - 范围/AOE技能不受嘲讽影响。
  - 嘲讽激活时，身体周围浮现荆棘光环（红色线框+半透明红色填充）。

**5. 队长加成：铁壁军团**
- **名称**：铁壁军团
- **效果**：全队获得+50点临时HP，战斗开始时生效。
- **触发条件**：荆铁担任队长时，战斗开始时全体友方角色额外获得50点临时生命值。
- **机制细节**：临时HP在真实HP之前被消耗，战斗结束后不保留。

**6. 升星强化表**

| 星级 | 机制变化 |
|------|----------|
| 1星 | 基础减伤各档位+5%（25%/40%/55%/70%） |
| 2星 | 队长加成激活时，胸甲纹章持续发光——嘲讽CD减少1回合（CD变为2回合） |
| 3星 | 嘲讽期间附带反伤效果，反震伤害=受到伤害的15% |
| 4星 | 临时HP提升至80点，盾面新增荆棘缠绕浮雕 |
| 5星 | 嘲讽激活时，荆棘光环扩大至包围全队——全队额外获得10%百分比减伤（嘲讽期间） |
| 6星 | 觉醒形态：铠甲碎裂脱落，荆棘编织成全身护甲覆盖身躯。失去"先锋"职业，被动变为"荆棘领域"——全场敌方攻击时，20%伤害被荆铁的荆棘领域吸收反弹。HP上限提升至200 |

**7. 同职业对比：荆铁 vs 磐姬**
- 减伤类型不同：荆铁是**百分比减伤**（越残血越硬），磐姬是**固定减伤**（越挨打越厚）。
- 护团方式不同：荆铁通过**嘲讽**将全部伤害吸引到自己身上，磐姬通过**伤害分摊**让队友少受50%伤害。
- 队长加成不同：荆铁加**临时HP**（额外血量），磐姬加**固定减伤**（伤害削减）。
- 视觉风格不同：荆铁是"铁甲+荆棘"的凄烈美感，越受伤越残破；磐姬是"石甲+玉石"的沉稳美感，越挨打越坚厚。

#### 05. 磐姬

**1. 角色定位说明**
- **核心定位**：前排固定减伤坦克，越挨打越厚，以伤害分摊和反震控场守护全队。
- **设计思路**：以"磐石蓄能"为核心概念——每受一击便多结一层玉石鳞片，层层堆叠既减伤又反震。区别于荆铁的"自损式防御"，磐姬是"越战越坚"的累积式防御。玉石结界技能使她能为全队分摊伤害，反震机制让攻击者付出代价。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 150 | 全角色最高（与荆铁并列） |
| ATK | 8 | 全角色最低（与荆铁、神无月、曦和并列） |

**3. 被动技能：磐石蓄能**
- **名称**：磐石蓄能
- **效果描述**：每次受到攻击时，获得1层"磐石"效果。每层磐石提供固定减伤15点和反震10点伤害。磐石层数最多叠加3层（基础）。
- **触发条件**：受到攻击命中时获得1层磐石，常驻被动。
- **机制细节**：
  - 每层磐石：固定减伤+15，反震伤害+10。
  - 基础最大层数：3层。满层时固定减伤45点，反震30点。
  - 磐石层数在整场战斗中持续累积，不会随回合消失。
  - 属于固定减伤，在百分比减伤之前计算。
  - 视觉表现：受击部位浮现翡翠色玉石鳞片，结晶点闪烁白光。

**4. 主动技能：玉石结界**

#### 06. 夜鸩

**1. 角色定位说明**
- **核心定位**：持续毒伤刺客，以鸩毒DOT削弱敌方，以剧毒穿透无视防御。
- **设计思路**：以"鸩毒叠层"为核心概念——每次攻击都在对方身上种下剧毒，毒层越多伤害越高、削弱越强。区别于椿偶的"一击爆发"，夜鸩走"持续削弱"路线。剧毒穿透技能体现毒的本质——无视一切防御，直取性命。

**3. 被动技能：鸩毒缠身**
- **名称**：鸩毒缠身
- **效果描述**：攻击命中时，对目标附加1层"鸩毒"。每层鸩毒在每回合开始时造成5点毒伤，并降低目标1点ATK。鸩毒最多叠加3层（基础）。
- **触发条件**：攻击命中时附加1层鸩毒，常驻被动。
- **机制细节**：
  - 每层鸩毒：每回合5点毒伤 + 降1ATK。
  - 基础最大层数：3层。满层时每回合15点毒伤，降3ATK。
  - 鸩毒持续至战斗结束，不会自然消失。
  - 毒伤结算时机：每回合开始时。
  - 毒伤属于真实伤害，无视减伤和护盾。
  - 视觉表现：目标身上浮现幽绿色鸩毒标记（花瓣形），每回合闪烁结算。

**4. 主动技能：剧毒穿透**
- **名称**：剧毒穿透

- **机制细节**：

  - 附加3层鸩毒：直接将目标鸩毒层数+3（不超过最大层数上限）。
  - 沉寂：使用技能后的下一个己方回合，夜鸩无法进行任何行动（普攻、技能、锦囊均不可用）。
  - 视觉表现：胸口夜鸩花胎记扩散发亮，毒脉纹路蔓延全身，指尖荧光穿透一切防御光效。

- **名称**：毒雾弥漫
- **效果**：全队角色攻击命中时，对目标附加1层鸩毒。
- **触发条件**：夜鸩担任队长时，全体友方角色的攻击均可为目标附加鸩毒。
- **机制细节**：

### 祭司组

#### 04. 神无月

**1. 角色定位说明**

- **设计思路**：以"月蚀消减"为核心概念——月神之力用于削弱而非增长，越是靠近月神之力的人越会被削弱。走辅助控场路线，区别于曦和的进攻灼烧路线。双技能设计对应月相双面——上弦月（单向削弱）与满月（双向削弱）。自愈被动呼应月相盈亏循环。

**3. 被动技能：月盈自愈**

- **触发条件**：使用主动技能后触发，常驻被动。
- **机制细节**：
  - 恢复量 = 最大HP × 5%（即4点HP/次，80HP时）。
  - 两个主动技能（月蚀·单蚀、月蚀·双蚀）使用后均触发此被动。

  - 降ATK：目标ATK-5，最低降至1（不能为0或负数）。
  - 持续时间：2回合，从被标记的下一回合开始计算。

- **消耗/代价**：消耗2点行动力，CD 4回合。自身也会被降ATK（反噬）。
- **机制细节**：
  - 选择目标：指定一名敌方角色。
  - 双向降ATK：神无月自身ATK-8，目标ATK-8。最低均降至1。
  - 持续时间：2回合。
  - 使用此技能后同样触发被动自愈。
  - 视觉表现：神杖顶端新月旋转为满月，自身与目标之间浮现双向红色光链，两人脚下各出现月蚀阵纹。

## 第四部分：职业对位关系总览

### 先锋对位：荆铁 vs 磐姬

| 维度 | 荆铁 | 磐姬 |
|------|------|------|
| **减伤类型** | 百分比减伤（越残血越硬） | 固定减伤+反震（越挨打越厚） |
| **核心机制** | 荆棘共生：HP分四档对应20%/35%/50%/65%减伤 | 磐石蓄能：每层固定减伤15+反震10，基础3层 |
| **护团方式** | 嘲讽：吸引全部指向性攻击到自己身上 | 玉石结界：友方伤害50%由磐姬分摊+反震翻倍 |
| **队长加成** | 全队+50临时HP（额外血量） | 全队固定减伤10点（伤害削减） |
| **优势场景** | 面对低频高伤爆发（如刺客大招） | 面对高频低伤攻击（如多段连击） |
| **劣势场景** | 持续多段攻击将HP卡在高减伤档位前 | 单次超高伤害击穿固定减伤 |
| **视觉主题** | 铁甲+荆棘，越伤越密，凄烈破碎之美 | 石甲+玉石，越击越厚，沉稳温润之美 |
| **设计哲学** | "以自身之残，换队友之全"——牺牲型守护 | "以自身之坚，承众人之重"——分担型守护 |

**差异化总结**：荆铁与磐姬虽然同为先锋坦克，但防御路线完全不同——荆铁走"百分比减伤+嘲讽"的单兵承伤路线，是团队的"盾牌"；磐姬走"固定减伤+分摊+反震"的团队共担路线，是团队的"城墙"。前者将伤害集中于自身，后者将伤害分散于团队。选择荆铁意味着相信一个人的绝对防御，选择磐姬意味着相信团队的共同承受。

### 刺客对位：椿偶 vs 夜鸩

| 维度 | 椿偶 | 夜鸩 |
|------|------|------|
| **伤害类型** | 即时爆发物理伤害 | 持续毒伤DOT+降攻 |
| **核心机制** | 主动攻击+5ATK，自伤换攻 | 攻击附带鸩毒（每层5伤+1降攻），最多3/5层 |
| **主动技能** | 落椿·自损：自伤25%HP，本回合+5ATK | 剧毒穿透：无视减伤/护盾+3层鸩毒，下回合无法行动 |
| **代价形式** | HP（自损血量） | 时间（跳过下回合） |
| **队长加成** | 全队反击+5ATK | 全队攻击附带1层鸩毒 |
| **对坦克威胁** | 中等（高ATK被高减伤稀释） | 极高（穿透无视减伤+毒伤真实伤害） |
| **优势场景** | 快速击杀低防脆皮 | 持久战，毒层叠加后伤害爆炸 |
| **视觉主题** | 瓷白人偶+黑发红瞳，诡异破碎之美 | 妖冶毒花+深紫幽绿，致命吸引之美 |
| **设计哲学** | "以自身之碎，换敌首之落"——爆发型刺客 | "以自身之毒，蚀敌骨于无形"——持续型刺客 |

**差异化总结**：椿偶与夜鸩虽然同为高攻刺客，但输出节奏完全不同——椿偶走"自伤爆发"的速杀路线，追求一击毙命，是"白刃刺客"；夜鸩走"毒伤累积"的磨血路线，追求持续削弱，是"毒系刺客"。前者的代价是鲜血，后者的代价是时间。选择椿偶意味着追求极致的爆发快感，选择夜鸩意味着享受慢慢蚕食对手的掌控感。

### 斥候对位：影翎 vs 蜃景

| 维度 | 影翎 | 蜃景 |
|------|------|------|
| **核心方向** | 信息获取+资源增益（看穿+加速） | 幻象欺骗+资源破坏（误导+封锁） |
| **被动技能** | 每回合+1行动力（己方加速） | 50%几率替换对方锦囊为蜃影（对方浪费） |
| **主动技能** | 鸦之视野：查看并弃置对方2张手牌 | 蜃之封印：展示并永久封印对方1张手牌 |
| **手牌操作** | 弃置（临时移除，可回收） | 永久封印（本局移除，不可逆） |
| **队长加成** | 己方锦囊牌免行动力（增益型） | 对方锦囊牌消耗+1行动力（削弱型） |
| **信息优势** | 我知道你有什么（信息透明） | 你不知道什么是假的（信息迷惑） |
| **优势场景** | 锦囊牌多、依赖技能的卡组 | 依赖关键牌、Combo型卡组 |
| **视觉主题** | 墨绿暗紫+灵鸦异色瞳，灵动元气之美 | 沙金天蓝+蜃之眼薄纱，飒爽幻影之美 |
| **设计哲学** | "看穿一切虚假，掌握真实节奏"——洞察型斥候 | "制造一切幻象，封锁敌方行动"——幻术型斥候 |
| **核心意象** | 鸦之眼——窃取真实 | 蜃之眼——编织虚假 |

**差异化总结**：影翎与蜃景虽然同为斥候，但战术逻辑完全相反——影翎是"看穿派"，通过获取真实信息和加速自方节奏来建立优势，是光明正大的情报战；蜃景是"欺骗派"，通过制造虚假幻象和封锁敌方资源来制造混乱，是虚实难辨的心理战。前者让你"知道得更多"，后者让你"知道的都是错的"。选择影翎意味着用信息差碾压对手，选择蜃景意味着用欺骗感玩弄对手。

### 祭司对位：神无月 vs 曦和

| 维度 | 神无月 | 曦和 |
|------|--------|------|
| **核心方向** | 辅助减攻+自愈（月蚀消减） | 持续灼烧+输出（日轮焚毁） |
| **被动技能** | 技能后自愈5%HP（向内恢复） | 回合结束灼烧目标5点（向外输出） |
| **技能一** | 月蚀·单蚀：单体降ATK 5点，持续2回合 | 日轮·初灼：单体灼烧8点/回合，持续3回合，ATK>10额外降2ATK |
| **技能二** | 月蚀·双蚀：双方降ATK 8点（反噬：自身降攻） | 日轮·共焚：双方灼烧8点/回合（反噬：自身受灼） |
| **反噬类型** | 降自身ATK（力量被消） | 自身受灼烧伤害（生命被焚） |
| **队长加成** | 全队技能冷却-1（循环加速） | 友方使用技能时随机敌方灼烧（附加伤害） |
| **团队定位** | 纯辅助（削弱对方+保护队友） | 进攻型辅助（持续伤害+削弱） |
| **优势场景** | 对方高ATK物理输出队 | 对方高HP坦克队/持久战 |
| **视觉主题** | 银白淡紫+月环巫女，清冷疏离之美 | 金红琥珀+日轮祭司，灼热英气之美 |
| **设计哲学** | "月蚀万物之力，独守己身之静"——消减型祭司 | "日轮焚尽一切，虽千万人吾往矣"——焚毁型祭司 |
| **核心意象** | 月——盈亏循环，消减清冷 | 日——永燃不息，热烈灼人 |

**差异化总结**：神无月与曦和虽然同为祭司双技能角色，但功能定位完全相反——神无月是"月之祭司"，走纯辅助路线，以月蚀之力削弱对方攻击，以自愈维持生存，是团队的"镇定剂"；曦和是"日之祭司"，走进攻型辅助路线，以日轮之力持续灼烧对方，以共焚换取爆发伤害，是团队的"催化剂"。前者让敌人"打不动"，后者让敌人"活不长"。二者互为日月对照——一个清冷一个热烈，一个内敛一个外放，一个守护一个焚毁。选择神无月意味着稳扎稳打的消耗战，选择曦和意味着轰轰烈烈的速决战。
