## ── 祭司「神无月」 ──

> **风格定位：日式赛璐璐风格（Cell-shading）**
> 以和风神职美学为核心，融合幻想祭司元素与美少女的清冷气质。赛璐璐上色强调衣袂飘飘的流动感、神圣光辉的平面光效，以及月相变化的装饰性纹样。整体色调清冷柔和，以白色与淡紫为主，营造「月下神域」的空灵氛围。她是「触碰不到的美」——因力量而疏离，因疏离而更美。

## 二、角色背景故事

神无月出生在大陆中央的「无月神社」，是世代侍奉月神「ツキヨミ」的巫女一族后裔。她出生那夜恰逢「神无月」——十月，诸神离去之月，天穹无月。族中长老说她是「神弃之子」，命带孤煞。

然而事实恰恰相反。她并非被月神抛弃，而是被月神选中——作为容器。她的身体中封印着月神的一缕分魂，这使她拥有削弱他人力量的能力：以月蚀之力侵蚀对方的攻击力。代价是，她自身的攻击力同样微弱——月神之力用于「消减」而非「增长」。

她性情温和但疏离，说话轻声细语，仿佛怕惊扰了体内的神魂。她从不与人亲近，因为她的力量会无差别地削弱身边所有人的活力。这让她习惯了孤独——美丽，却触碰不到。

口头禅是：「靠近我的话……会变弱的哦。」

> **美少女特征要点**：属于「清冷疏离」型角色——银发紫瞳、和风巫女装束、月环虚影，是最具「正统美少女」外形的角色。但她的美带着悲剧性：她越是美丽，越是不能被触碰；她越是温柔，越是不敢靠近任何人。她是四人中外表最柔弱、气质最空灵的一个。月环、符纸、银发飘扬——她的每个元素都在营造一种「随时会化为月光消散」的虚幻美。

## 三、外貌设计

### 3.1 面部特征

- **脸型**：鹅蛋脸，轮廓柔和，下巴圆润。五官精致端正，是那种「如月般宁静」的美——不张扬，却令人移不开目光
- **眼睛**：大而圆润的杏眼，微微下垂，眼尾含愁，是那种「楚楚可怜」的眼型。
  - 虹色为淡紫色（#9A7AB8），瞳孔为细长的椭圆形（非圆形，暗示非人神性）
  - 赛璐璐处理：瞳孔分三层——外圈淡紫底色、内圈深紫环（#6A4A88）、中心黑色瞳孔。高光为两个错位的弯月形白点（而非圆点），呼应月相主题
  - 大而含愁的紫色杏眼是她的标志性美少女特征——那种「眼睛里仿佛映着月亮」的梦幻感
- **眉毛**：细长弧形眉，微微蹙起，带着淡淡的忧愁。眉形柔和如新月
- **鼻子**：小巧精致，鼻梁纤细
- **嘴唇**：饱满的樱桃唇，嘴角微微下弯，唇色为淡粉色（#D8A0A8），似涂薄粉。不笑时自带忧郁，笑时如月华初升
- **面容**：肤色极白近乎透明，太阳穴处可见淡紫色血管纹路（神灵侵蚀的痕迹）。透明的肌肤在月环光辉下仿佛在发光

### 3.2 发型发色

- **发色**：银白色（#D8D0E0），发根处略带淡紫色，发梢渐变为淡蓝紫（#B8A8D0）
- **发型**：极长发，垂至腰下。上半部用白色发带束为高马尾，马尾自然垂落如月华倾泻。前额为薄薄的空气刘海，两侧各有一束长发垂于胸前。银白长发如月光瀑布，是全角色发量最长、最飘逸的一个
- **发饰**：马尾根部系有一枚新月形银质发饰（上弦月造型），发饰垂下两条白色丝带飘带，飘带上绣有银色月相纹
- **质感表现**：头发用大块银白底色铺满，赛璐璐高光为一条贯穿头顶的冷蓝色反光带（#A8B8D8），发梢紫色部分用两段色阶硬切

### 3.3 体型身姿

- 纤细高挑的少女体型，肩窄腰细，体态柔软如柳
- 站姿端正，双手交叠于身前持杖，微微低头。站姿优雅而端正，如神社中供奉的巫女人偶
- 给人一种「随时会随风飘散」的虚幻感
- 赛璐璐表现时刻意弱化身体线条，强调衣物的飘逸感而非体型曲线。但偶尔被风吹贴身的白衣会露出纤细的腰线

## 四、服装设计

### 4.1 神职装束——和风巫女×幻想祭司

- **上半身·白衣**：纯白色（#F0EDE8）的小袖白衣，宽袖，袖口垂长。衣身合体但不紧身，领口为V形交叠，露出纤细的脖颈和小片胸口。白衣表面有若隐若现的银线月相刺绣（满月→新月→满月的循环纹样），近看才能发现
- **下半身·绯袴**：深紫红色（#6A3A5A）的和风行灯袴（灯笼裤式），宽大飘逸，袴脚扎入足袋。袴的布料表面有暗紫色的云纹织花。宽大的绯袴衬托出她纤细的腰身
- **外罩·羽织**：一件无袖的半透明白色羽织（薄纱质感），从肩部披挂至膝，边缘绣有银色新月纹饰。羽织在风中飘动时透出内层白衣的轮廓，如月光薄纱

### 4.2 腰带与配饰

- **腰带**：宽幅的银白色织带，系法为和风结——结形为花朵状（椿花造型），结头垂下两条长飘带，飘带上串有银色铃铛
- **前挂**：腰前垂有一条银链，链上挂有三枚月牙形银牌（分别刻有满月、半月、新月的纹样），行走时轻轻碰撞发出清脆声响

### 4.3 神圣元素（核心视觉特征）

- **月环**：背后浮现一个巨大的银白色月环虚影（直径约身高的1.5倍），月环上刻有月相变化纹路，缓缓旋转。这是月神分魂的具象化。少女纤弱的身影立于巨大的月环前，构成强烈的比例对比
- **神纹**：双手手背处有淡紫色的月相纹路（如同纹身），使用技能时纹路会发光
- **飘浮符纸**：身体周围有3-5张白色符纸缓缓飘浮，符纸上用淡紫色墨水写有经文，是她的技能媒介

## 五、配饰与道具

### 5.1 武器——「月蚀」神杖

- **形态**：等人高的长杖，杖身为白色木质，杖顶为一枚新月形银质装饰，新月凹面朝上，中间嵌有一颗淡紫色球形宝石
- **细节**：杖身缠绕银色藤蔓纹饰，杖底为尖锐的金属尖头（可插地）
- **状态变化**：技能1激活时宝石由紫变红（标记敌方），技能2激活时新月旋转为满月（双方削弱）
- **赛璐璐表现**：杖身用白色平涂+银色纹饰线描，宝石用三层色阶（外圈淡紫、内圈深紫、中心高光白点），新月金属用银灰三段色阶

### 5.2 其他配饰

- **颈部**：戴有白色绳结项链，坠子是一枚小型的银质满月牌
- **耳饰**：左耳戴一枚新月形银耳坠，右耳无耳饰（不对称设计，呼应月相盈亏）
- **手部**：双手无名指各戴一枚银戒，戒面为月牙纹
- **足部**：白色分趾足袋+浅紫色草履

### 6.2 赛璐璐色阶规则

- 整体色阶层数偏少（2-3层），刻意营造「淡雅、空灵」的视觉效果
- 白衣使用暖白底色+淡灰紫阴影，阴影面积控制在20%以下，保持大面积留白
- 月环和符纸等神圣元素使用半透明色块叠加，不做复杂阴影
- 高光使用冷蓝色调（#C0D0E8），集中在头发、月环边缘和宝石上

## 七、赛璐璐风格表现要点

### 7.1 线稿

- 线条极细且柔和，粗细变化极小，营造纤细柔美的感觉
- 衣物轮廓线使用长弧线，线条末端渐细如毛笔收锋
- 面部五官用最细线（0.3-0.5px），眉眼间距略大，增强空灵感
- 月环和符纸的纹样用银色线（#C0C0C8）而非黑色线

### 7.2 上色

- 白衣褶皱阴影用极淡的灰紫色块，边缘清晰但色彩对比低，营造「若有似无」的阴影
- 袴的阴影用深紫红色块，方向统一，褶皱处用U形阴影
- 头发高光为一条冷蓝色连贯反光带，不分段
- 月环用半透明白色色块平涂，边缘加银色细线描边，不做内部阴影——保持虚幻感
- 符纸上的经文用淡紫色极细线描，不填色
- 皮肤上色刻意保持高明度低对比，营造「白到透明」的神圣感

### 7.3 特效层

- **被动激活（技能后自愈5%HP）**：身体周围浮现淡紫色光粒，缓缓向上飘散如萤火
- **技能1（标记敌方，降ATK）**：神杖宝石变红，射出一道红色光链连接目标，目标身上浮现月蚀纹（从满月渐变为新月的动画）
- **技能2（双方降ATK）**：神杖顶端新月旋转为满月，自身与目标之间浮现双向红色光链，两人脚下各出现一个月蚀阵纹
- **队长加成（冷却-1）**：所有友方角色技能图标外浮现银色月环
- **6星觉醒**：背后月环碎裂重组为星辰图案，衣袂飞舞更加剧烈

## 八、表情与姿态设计

### 8.1 默认立绘姿态

- 正面站立，身体微微侧向左侧，双手交叠于胸前持「月蚀」神杖竖立
- 头微微低垂，目光从上方安静地注视观者，嘴角带着淡淡的忧郁
- 羽织随微风向右飘扬，飘带和银白长发向同方向飘动
- 背后月环缓缓旋转，周围符纸飘浮
- 整体呈「静止中的流动」——少女安静但衣袂飘动。巨大的月环虚影在她身后缓缓旋转，银发如瀑垂落

### 8.2 表情变化

| 状态 | 表情描述 |
|------|----------|
| 默认 | 微微低头，嘴角略带忧郁，紫色杏眼温和但疏离。如月光般宁静而不可触及 |
| 技能1（标记） | 抬头直视目标，瞳孔中倒映出月蚀纹，表情冷冽。温柔的少女一瞬间变得如月神般威严 |
| 技能2（双方削弱） | 闭眼，眉头蹙起，嘴角下压——使用此技能时自身也会被反噬。痛苦的表情让人心生怜惜 |
| 被动自愈 | 表情柔和，嘴角微微上扬——少女极罕见的笑容，周身光粒飘散。如月华初升 |
| 6星觉醒 | 月环碎裂，睁眼时瞳孔变为银色星辰纹，表情从忧郁变为释然微笑。银发在碎裂的月光中飞舞——终于可以触碰别人了 |

## 十、标志性画面

### 概念场景描述

「月光下，她独自站在神社的鸟居前。银白长发如瀑垂落，背后巨大的月环缓缓旋转，将银色的光辉洒落满地。她抬起神杖，杖顶新月映照着天上的残月——两轮月亮遥遥相对。敌人冲来，她轻轻一挥杖，红色的月蚀纹便爬上了对方的武器，刀剑变得沉重如山。少女低声说：'我说了……靠近我会变弱的。'——她的语气不像警告，更像一句带着歉意的叹息。」

> 画面构图：正面构图，神无月位于画面正中央，持杖而立。背后巨大的月环虚影占据画面上半部分，银色光辉从月环洒下形成放射状光线（用赛璐璐方式的白色线条+半透明色块表现）。地面铺满月光，她的倒影在地面月光中呈现为另一个姿态（暗示月神分魂）。飘浮的符纸环绕在她身周，经文微微发光。羽织和银白长发向左侧飘动，右下角是冲来的敌人被月蚀纹侵蚀武器的局部画面。整体色调为银白+淡紫，是四个角色中色彩最清冷的一张。少女纤弱的身形立于巨大的月环之下，像一朵月光凝成的花。

## 十一、升星视觉变化一览

| 星级 | 视觉变化 |
|------|----------|
| 1星 | 神杖杖身多出一道银色月相纹路 |
| 2星 | 所有技能激活时，月环旋转加速（冷却减少的可视化） |
| 3星 | 月环外圈多出一层暗金色边框（反伤减免） |
| 4星 | 神杖宝石增大，光泽更亮，白衣月相刺绣变为可见银色 |
| 5星 | 自愈时光粒从淡紫变为金紫色，数量翻倍（自愈效果增强） |
| 6星 | 月环碎裂化为星辰散落，瞳孔变为银色星辰纹，衣袂无风自动——月神离开容器，银发少女不再需要神职身份。她伸出双手，第一次可以触碰别人而不使对方变弱。从一个「容器」变回了「少女」，从一个「不可触碰的神」变回了「可以拥抱的人」 |
