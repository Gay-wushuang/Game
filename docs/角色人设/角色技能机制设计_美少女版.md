## 第一部分：游戏机制术语说明

### HP（生命值）

- **定义**：角色的生存能力数值，代表角色能够承受的伤害总量。HP归零则角色阵亡，退出战斗。
- **归零效果**：角色进入阵亡状态，不能行动、承受新的普通伤害或成为存活目标。角色及槽位至少保留到本次伤害的 `HERO_DIED`、复活与死亡后响应全部结算完毕；未被复活时才清空槽位。阵亡角色自身的普通被动不再触发，但明确标记为“阵亡时”的效果仍可触发。
- **与角色定位关系**：先锋职业HP最高（150），承担前排承伤职责；刺客HP最低（70-80），属于脆皮输出；斥候HP居中（100），平衡生存与机动；祭司HP较低（80），属于辅助/输出位。

### ATK（攻击力）

- **定义**：角色普通攻击造成的基础伤害值。
- **基础值范围**：刺客最高（椿偶20、夜鸩17），斥候居中（10），先锋（荆铁10、磐姬9）与祭司（神无月5、曦和6）较低。

### 回合与时点

#### 回合定义

- **己方回合**：当前玩家的行动回合。在己方回合内，玩家可以控制己方角色进行普通攻击、释放主动技能、打出锦囊牌等操作。
- **敌方回合**：对方玩家的行动回合。在敌方回合内，己方角色处于被动状态，仅触发被动/反击效果。
- **完整轮次**：一次己方回合 + 一次敌方回合 = 一个完整轮次。

#### 结算时点

| 时点 | 触发时机 | 典型效果 |
|------|----------|----------|
| 战斗开始时 | 战斗正式开始前的最后一步 | 队长加成生效、入场效果 |
| 所属阵营回合开始时 | 状态持有者所属阵营行动阶段开始前 | DOT结算（鸩毒）、磐石衰减、行动力回复、影翎+1AP |
| 攻击命中时 | 普通攻击或技能攻击命中目标后 | 叠层效果（磐石、鸩毒）、反震 |
| 受击时 | 角色受到伤害时 | 分段减伤（荆铁）、受击类被动 |
| 使用技能后 | 主动技能释放结算完成后 | 神无月自愈、曦和队长灼烧 |
| 所属阵营回合结束时 | 状态持有者所属阵营行动阶段结束后 | DOT结算（灼烧）、持续效果剩余次数-1 |

#### 持续效果的计时规则

- 禁止只写含糊的“持续N回合”。角色状态默认以**状态持有者所属阵营的行动回合**计时；需要按来源阵营或完整敌我轮次计时的效果必须单独注明。
- 效果在施加后立即生效，但施加当刻不消耗持续次数。例：己方对敌方施加“持续目标方2个行动回合”的降ATK，则覆盖敌方接下来的2个行动回合，并在敌方第2个行动回合结束后移除。
- DOT每个完整敌我轮次最多结算一次：鸩毒在状态持有者所属阵营回合开始时结算；灼烧在状态持有者所属阵营回合结束时结算。

### 伤害结算顺序（统一规则）

伤害按照以下顺序逐层结算，**不可颠倒**：

1. **固定减伤**：先扣除固定数值的减伤量
2. **百分比减伤**：剩余伤害再乘以（1 - 百分比减伤）
3. **护盾**：经过减伤后的伤害，先由护盾吸收
4. **临时HP（TempHP）**：护盾被击穿后，由临时HP吸收
5. **HP**：最后才扣除角色的真实HP

> **关键说明**：护盾吸收的是**经过减伤后的伤害**，不是原始伤害。即减伤先于护盾生效。

**公式**：
```
步骤1：固定减伤后 = max(0, 基础伤害 - 有效固定减伤)
步骤2：减伤后伤害 = RoundToInt(固定减伤后 × (1 - 百分比减伤))
步骤3：若该伤害允许最低伤害，则伤害 = max(1, 减伤后伤害)
步骤4：护盾吸收伤害，剩余伤害继续
步骤5：临时HP吸收伤害，剩余伤害继续
步骤6：扣除角色HP
```

### 最低伤害规则

- 普通攻击、技能伤害和DOT在完成全部减伤并四舍五入后，伤害值最低为1。
- 被取消的伤害为0；明确写作“生命流失”的效果可绕过减伤和最低伤害规则。
- 最低1点是进入护盾前的伤害值，护盾或临时HP仍可将实际HP损失降为0。

### 伤害转移与递归规则

为防止无限递归和平衡性崩坏，以下规则强制生效：

1. **分摊/转移的伤害不能再次被分摊或转移**
   - 被分摊到磐姬身上的伤害，不能再被任何分摊/转移效果二次转移。
   - 即伤害转移只生效一次，不链式传递。

2. **反震/反伤造成的伤害不触发反震、反伤、分摊**
   - 反震伤害是"反弹"的伤害，不是"攻击"，因此不会触发对方的反震、反伤或分摊机制。
   - 防止出现"A打B→B反震A→A反震B→..."的无限递归。

3. **DOT伤害不视为"受到攻击"，不触发受击类被动**
   - 鸩毒、灼烧等持续伤害属于DOT，不触发：磐石叠层、反震、受击回血、受击减伤等"受击时"触发的效果。
   - DOT伤害直接走伤害结算流程（固定减伤→百分比减伤→护盾→临时HP→HP）。

4. **护盾完全吸收伤害时，不触发受击叠层和反震**
   - 如果伤害被护盾完全吸收（即没有扣到临时HP或HP），则不视为"真正受击"。
   - 此时不触发：磐石叠层、反震、受击类被动技能。
   - 如果护盾只吸收了部分伤害（剩余伤害扣到了临时HP或HP），则视为受击，触发相关效果。

5. **每次伤害最低造成1点**（见"最低伤害规则"）

6. **自伤不触发受击类效果**
   - 角色对自身造成的伤害（如椿偶的自损、曦和的共焚反噬）不视为"受到攻击"。
   - 自伤不触发：磐石叠层、反震、受击回血、受击减伤等"受击时"触发的效果。
   - 自伤走正常伤害结算流程（固定减伤→百分比减伤→护盾→临时HP→HP）。
   - 但技能描述中明确写"无视减伤"的自伤除外（如椿偶自损直接扣HP）。

### 临时HP（TempHP）

- **定义**：独立于HP上限的额外伤害吸收池，先于HP消耗。
- **与HP上限的区别**：
  - 临时HP是**伤害吸收层**，不计入最大生命值，不能被治疗效果恢复。
  - 最大生命提升（MaxHP+）是**永久增加HP上限**，当前HP同步增加，可以被治疗。
  - 护盾（Shield）是**另一个独立吸收层**，在临时HP之前被消耗，也不计作HP。

| 属性 | 临时HP | 最大生命提升 | 护盾 |
|------|--------|-------------|------|
| 性质 | 伤害吸收池 | HP上限增加 | 伤害吸收层 |
| 能否被治疗 | 不能 | 能（治疗HP） | 不能 |
| 消耗顺序 | 护盾之后、HP之前 | —（就是HP本身） | 最优先 |
| 战斗结束后 | 消失 | 保留 | 消失 |
| 叠加方式 | 可叠加（可超过初始值） | 可叠加 | 可叠加 |

**队长加成相关规则**（以荆铁队长为例）：
- 荆铁队长加成为**临时HP**，不是"生命上限"。
- 队长死亡后，已经获得的临时HP**不消失**（临时HP是施加在角色身上的效果，不因来源消失而清除）。
- 后部署的英雄入场时**获得临时HP**（队长光环在战斗开始时和新角色入场时均生效）。
- 不同来源的临时HP可以叠加。同一来源对同一角色默认只授予一次；复活、重新入场或刷新光环不会重复领取，除非技能明确说明。

### 护盾

- **定义**：一种可以吸收伤害的临时保护层，在伤害结算中优先于临时HP和HP被消耗。
- **结算顺序**：护盾在固定减伤和百分比减伤**之后**才开始吸收。
- **特点**：
  - 护盾完全吸收伤害时，不触发受击类被动（如磐石叠层、反震）。
  - 护盾有持续时间或数值上限，战斗结束后消失。
  - 多层护盾叠加时，按施加顺序或数值统一消耗（具体视技能描述）。

### 减伤机制

#### 固定减伤

- **定义**：受到伤害时，先扣除固定数值的减伤量。
- **特点**：对低额多次攻击效果极佳，对高额单次攻击效果有限。
- **代表**：磐姬的磐石层数（每层固定减伤10点）、磐姬队长加成（全队固定减伤10点）。

#### 百分比减伤

- **定义**：受到伤害时，按百分比削减伤害。
- **特点**：对高额单次攻击效果极佳，对低额多次攻击效果有限。
- **代表**：荆铁的分段减伤（越残血减伤百分比越高）。

#### 叠加关系

- 先计算固定减伤，再计算百分比减伤。即：**减伤后伤害 = (基础伤害 - 固定减伤) × (1 - 百分比减伤)**。
- 固定减伤有多个来源时，数值直接相加。
- 百分比减伤有多个来源时，采用加法叠加（如10% + 20% = 30%）。
- **固定减伤总上限**：固定减伤总值不超过**本次伤害**的80%（即至少受到20%的伤害）。超过部分无效。此上限在固定减伤阶段结束时检查。

### DOT（持续伤害）——实例化模型

#### 统一数据模型

每层DOT是一个**独立实例**，携带以下信息：
- **伤害值**：每层每次结算造成的伤害
- **剩余持续回合数**：还能持续多少回合
- **来源**：施加该DOT的角色/技能

DOT实例自带**结算时点属性**（这是DOT本身的特性，不依赖任何角色被动）：
- 鸩毒：状态持有者所属阵营回合**开始时**结算
- 灼烧：状态持有者所属阵营回合**结束时**结算
即DOT的伤害完全由实例本身决定，结算时点是DOT类型的固有属性。

#### 鸩毒实例

- **伤害值**：每层伤害值由来源决定（如夜鸩被动每层5点，剧毒穿透每层5点）。
- **持续时间**：持续至战斗结束或被净化；净化鸩毒层时同步恢复该层造成的ATK降低。
- **附带效果**：每层降低目标1点ATK（降攻效果与层数同步存在）。
- **结算时点**：状态持有者所属阵营回合开始时结算，每个完整敌我轮次最多一次。
- **叠加规则**：每层独立存在，各自结算伤害。ATK降低效果为各层数值之和；达到上限后再次施加无效，不刷新其他层。来源阵亡不移除已有层数。
- **最大层数**：基础3层，2星后5层（视角色升星而定）。

#### 灼烧实例

- **伤害值**：每层伤害值由来源决定（如初灼每层8点，队长灼烧每层5点）。
- **持续时间**：有固定持续回合数（如初灼3回合、共焚2回合）。
- **结算时点**：状态持有者所属阵营回合结束时结算，每个完整敌我轮次最多一次；结算后剩余次数-1，归零则该层消失。
- **附带效果**：部分灼烧附带条件降攻（如ATK>10时额外降2ATK），降攻持续时间与灼烧同步。
- **叠加规则**：每层独立存在，各自结算伤害和持续时间。同一技能在同一目标上的灼烧实例上限为2层；达到上限后再次施加时，刷新剩余时间最短的一层，不新增第三层。不同来源分别计算此上限。

> **说明**：灼烧DOT的回合结束结算时点是其固有属性，不依赖任何角色被动。曦和的"炎威"被动是对灼烧伤害的**额外强化**，详见曦和角色机制。

#### DOT与反伤/克制的关系

- DOT伤害**不触发克制反伤**（因为DOT不是"攻击"，不触发攻击相关的反伤机制）。
- 反伤只在**普通攻击**和**技能攻击命中**时触发。
- DOT伤害走正常伤害结算流程（固定减伤→百分比减伤→护盾→临时HP→HP），但不触发"受击时"类效果。

### Debuff（减益效果）

- **定义**：施加在敌方角色身上的负面效果，削弱其战斗能力。
- **类型**：
  - **降ATK**：降低目标的攻击力数值。可来自直接降攻技能，也可来自DOT附带效果。
  - **禁止行动**：使该英雄不能普通攻击、反击或释放主动技能；仍可成为目标且普通被动继续生效。它不禁止所属玩家部署英雄或使用共享手牌中的锦囊。如夜鸩的“沉寂”。
  - **行动力消耗增加**：使对方使用锦囊牌时需要消耗更多行动力。如蜃景队长加成。
  - **DOT（鸩毒/灼烧）**：持续伤害类减益，部分附带降攻。
  - **放逐/封印**：使锦囊牌进入放逐区，本局内无法使用。
- **持续时间**：不同Debuff持续时间不同，必须写明按状态持有者阵营回合、来源阵营回合或完整敌我轮次计时，不得只写“持续N回合”。

### Buff（增益效果）

- **定义**：施加在己方角色身上的正面效果，增强其战斗能力。
- **类型**：
  - **攻击力提升**：临时或常驻增加ATK数值。
  - **行动力增加**：每回合获得额外行动力。
  - **免行动力/费用减免**：使用锦囊牌时不消耗行动力或费用降低。
  - **减伤提升**：增加固定或百分比减伤。
  - **临时HP**：获得额外的伤害吸收池。
  - **冷却减少**：技能冷却时间缩短。
  - **嘲讽**：强制敌方攻击自己（属于状态类效果）。

### 嘲讽

- **定义**：强制敌方将攻击目标转向自己的技能效果。
- **重定向范围**（修正后）：
  - 嘲讽只重定向：**敌方发起的单体普通攻击** + **明确标记为"可被嘲讽重定向"的敌方单体技能**。
  - **不受嘲讽影响**：主动锦囊牌、范围/AOE技能、随机目标效果、伤害转移效果。
  - **已锁定目标后才获得嘲讽的效果不回溯**：即攻击已经选定目标后，目标才获得嘲讽，这次攻击不会被重定向。
- **持续时间**：嘲讽有持续回合数，在持续期间内生效。

### 反震/反伤

- **定义**：受到攻击时，将部分伤害反弹给攻击者的效果。
- **触发条件**：每次受到攻击命中（且伤害没有被护盾完全吸收）时触发。
- **递归限制**：反震造成的伤害不触发对方的反震、反伤、分摊（见"伤害转移与递归规则"）。
- **反震上限**：反震伤害不超过本次实际承受伤害的100%（反震不能比实际受伤还多）。
  - "本次实际承受伤害"指的是：经过固定减伤、百分比减伤、护盾、临时HP后，**实际扣除HP的伤害量**。
  - 如果伤害完全被护盾/临时HP吸收（没扣到HP），则反震不触发（与护盾完全吸收不触发受击一致）。
- **代表**：磐姬的磐石反震（每层反震8点伤害）。

### 反击与反伤的区别

- **反伤（反震）**：被攻击时，攻击者受到的反弹伤害（是攻击者受到的伤害）。反伤数值 = 被攻击者ATK × 反伤比例，或固定数值（如磐石反震）。克制关系调整反伤比例。
- **反击**：被攻击后，被攻击者对攻击者进行的一次回击（是被攻击者发起的一次额外攻击）。反击伤害 = 被攻击者ATK × 反击增伤。反击视为一次普通攻击，触发攻击命中类效果（如叠毒）。
- **核心区别**：反伤是"反弹"（伤害来源是攻击本身），反击是"回击"（是一次额外的攻击行动）。
- **当前版本说明**：目前游戏中主要使用"反伤"机制。角色默认没有反击能力，反击能力需要通过特定技能或效果获得。
- **椿偶队长加成说明**：为避免能力在当前系统中成为空白效果，“傀儡反击”作用于现有反伤结算：友方受到普通攻击并产生反伤时，最终反伤值+5。它不授予额外攻击，也不触发攻击命中类效果。

### 伤害分摊

- **定义**：将原本由单个角色承受的伤害，部分转移给另一个角色承受的机制。
- **示例**：磐姬的玉石结界——友方受到的伤害50%由磐姬分摊承受。
- **递归限制**：分摊/转移的伤害不能再次被分摊或转移（见"伤害转移与递归规则"）。
- **分摊伤害的性质**：分摊到承受者身上的伤害，正常走伤害结算流程（固定减伤→百分比减伤→护盾→临时HP→HP）。是否触发"受击类"叠层效果，取决于具体技能的描述：
  - 若技能明确写"分摊伤害触发叠层"，则触发（如磐姬玉石结界）。
  - 若技能未明确说明，则默认不触发。

### 行动力（AP）

- **定义**：每回合可用于执行行动的资源点数，简称AP。
- **消耗方式**：普通攻击固定消耗1 AP；锦囊牌支付其实例费用；主动技能支付各自配置的AP费用，兼容技能可以配置为0。
- **与技能释放的关系**：数据结构逐技能保存AP消耗，行动力低于该技能费用时无法释放。
- **费用为0的效果**：
  - 使某张牌"本回合费用为0"的效果，仅改变行动力消耗，不改变牌的其他规则。
  - 0费牌仍受手牌规则和使用次数限制。
  - X费用牌（消耗全部AP的牌）不享受"费用为0"的效果。

### 手牌/锦囊牌

- **定义**：战斗中可使用的策略卡牌，即锦囊牌，存放在手牌区。

#### 弃牌
- 将手牌中的锦囊牌弃置到弃牌堆。
- 被弃置的牌本回合无法使用，后续可通过洗入牌库等方式回收。

#### 放逐（原"永久封印"）
- 被放逐的牌进入**放逐区**。
- 放逐区的牌：不计入手牌上限、不能被抽牌/检索/复制、战斗结束后还原。
- 放逐是**本局战斗内**的永久移除，不是删除卡牌本身。
- 代表：蜃景的"蜃之封印"。

#### 替换（蜃影）
- 将对方手牌中的某张牌替换为虚假的"蜃影"。
- 蜃影牌打出时无效，但仍消耗行动力。

### 放逐区

- **定义**：被永久封印（放逐）的牌所存放的独立区域。
- **区域规则**：
  - 放逐区的牌**不计入手牌上限**（不占用手牌位置）。
  - 放逐区的牌**不能被抽牌、检索、复制**等效果影响。
  - 战斗结束后，放逐区的牌**全部还原**回牌组（放逐是战斗内效果，不影响卡牌本身）。
  - 放逐区的牌对双方可见或不可见，视具体设计而定（推荐：己方可见己方放逐的牌）。

### 冷却时间（CD）

- **定义**：技能释放后需要等待的回合数，等待期间无法再次使用该技能。
- **每个技能可独立配置CD**：默认按技能ID独立计时；需要共享冷却的技能必须显式配置相同冷却组。
- **减少冷却的效果**：通过技能或队长加成缩短冷却时间。
  - 例：神无月队长加成"全队技能冷却-1"。
  - 技能CD最低为1回合（不能为0或负数）。
- **CD计算时点**：技能释放后进入CD；在技能使用者所属阵营回合结束时CD-1，CD归零后可再次使用。
- **冷却组**：神无月、曦和的两个技能当前设计为同一冷却组，使用其中任意一个后整组进入冷却。共享冷却是角色配置，不是祭司职业的永久规则。冷却减少作用于冷却组，最终CD最低为1。

### 被动技能

- **定义**：无需主动释放、在满足特定条件时自动触发的技能效果。
- **触发条件**：包括回合开始/结束时、受到攻击时、攻击命中时、使用技能后等。
- **特点**：不消耗行动力、没有冷却时间、不可被封印。

### 主动技能

- **定义**：玩家主动选择释放的技能，通常需要消耗行动力并有冷却时间。
- **消耗**：消耗一定数量的行动力（AP），部分技能有额外代价（如自伤、禁止下回合行动等）。
- **逐技能配置**：每个技能独立配置AP费用、基础CD和冷却组；不同技能可以配置相同数值，但不能依赖职业或角色编号推断。
- **当前05-08配置**：本稿中的05-08号主动技能暂定0 AP、基础CD 5；这是当前平衡参数，不是新增角色的永久统一规则。
- **双技能共享冷却**：神无月与曦和各自的两个技能当前配置为同一冷却组，使用任意一个后同组技能一起进入冷却。

### 队长加成

- **定义**：当角色担任队长时，为全队提供的常驻增益效果。
- **触发条件**：该角色被设为队长时，战斗开始时生效。
- **全队效果**：对己方所有角色生效，包括队长自身。
- **队长死亡后**：
  - 已经施加的**持续型效果**（如临时HP）不消失。
  - **光环型效果**（如每回合触发的效果）在队长死亡后不再触发。
  - 具体以各技能描述为准。
- **持续时间**：持续型队长光环基础持续5个队长所属阵营行动回合，每次该阵营回合结束后剩余次数-1；角色条目明确规定其他时长时从其规定。一次性授予效果不使用该计时。

### 职业定位

#### 先锋
- **核心定位**：前排坦克 / 伤害吸收 / 团队守护
- **职责**：站在队伍最前方承受敌方攻击，通过嘲讽、减伤、护盾、分摊等机制保护队友。
- **特点**：HP最高（150），ATK中等偏低（8-10），以生存能力和团队防护为核心价值。

#### 刺客
- **核心定位**：高攻脆皮 / 爆发输出 / 持续削弱
- **职责**：对敌方造成高额伤害，通过爆发或持续伤害快速削减敌方HP。
- **特点**：ATK最高（椿偶20、夜鸩17），HP最低（70-75），以高输出换取低生存。

#### 斥候
- **核心定位**：信息干扰 / 行动力操控 / 手牌破坏
- **职责**：通过信息获取、行动力增减、手牌干扰等方式掌控战斗节奏。
- **特点**：HP与ATK均为中等（100/10），以资源操控和信息差为核心价值。

#### 祭司
- **核心定位**：辅助控场 / 持续效果 / 双向影响
- **职责**：通过减益、增益、持续伤害或恢复等方式影响战场局势。
- **特点**：HP较低（80），ATK较低（5-6），但当前两名祭司拥有双主动技能，战术选择丰富。

### 升星系统

- **定义**：角色从0星到6星的成长系统，每个星级解锁或强化特定机制。
- **0-6星统一升星结构**：
  - 0星：基础形态
  - 1星：绝对数值突破（二选一：ATK +X 或 HP +Y）
  - 2星：专属特化（各角色独特机制强化）
  - 3星：通用反伤减免（被克制时反伤 ×0.75）——统一规则，全角色相同
  - 4星：绝对数值突破（二选一：另一项，即1星没选的那个）
  - 5星：二次特化（各角色更高级的机制强化）
  - 6星：终极质变——① 失去职业（变为"无职业"，脱离克制）；② 同时加 ATK 和 HP（绝对数值）
- **关于1星/4星二选一**：升星到1星时，玩家可从"ATK +X"和"HP +Y"中选择一项；升星到4星时，自动获得1星未选择的那一项（即两项都获得，但1星时先选一个）。
- **关于3星通用效果**：所有角色的3星都是"反伤减免：被克制时反伤 ×0.75"，没有角色特色。这是全局统一规则。
- **6星觉醒·失去职业**：角色突破到6星时进入觉醒形态，脱离原有职业身份束缚，详见下文"6星觉醒·失去职业（全局规则）"。

### 6星觉醒·失去职业（全局规则）

角色突破到6星时进入觉醒形态，脱离原有职业身份束缚。失去职业后遵循以下全局规则：

1. **职业克制**：不再参与职业克制——不克制任何职业，也不被任何职业克制，视为**中立**。
2. **职业限定效果**：不能再获得"仅限某职业"的效果（如"仅限先锋获得的buff"对6星觉醒角色无效）。
3. **已施加的职业相关效果**：已经施加在角色身上的职业相关buff/debuff**保留至持续时间结束**，不因失去职业而提前清除。
4. **组队限制**：6星队长在组队限制中视为"无职业"，不计入任何职业配额。
5. **技能替换**：6星觉醒时，被动技能替换为觉醒版被动技能；部分角色的主动技能也会合并或替换。
6. **HP上限提升**：6星觉醒时HP上限提升，同时**当前HP也同步增加同等数值**（相当于获得一次等额的治疗）。例如：HP上限从150提升至200，当前HP也+50。

## 第三部分：各角色详细机制设计

---

### 先锋组

#### 01. 荆铁

**1. 角色定位说明**
- **核心定位**：前排百分比减伤坦克，越残血越硬，以嘲讽和临时HP守护全队。
- **原版对应**：铁卫（iron_guard）的美少女化重命名版，核心机制保持兼容，数值与原版一致。
- **设计思路**：以"荆棘共生"为核心概念——受伤越重，荆棘越密，防御越强。区别于磐姬的固定减伤路线，荆铁走百分比减伤路线，对高额伤害的抗性更强。嘲讽机制使她成为团队的"人形城墙"，替队友承受所有指向性攻击。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 150 | 全角色最高（与磐姬并列） |
| ATK | 10 | 先锋中较高（沿用铁卫数据） |

**3. 被动技能：荆棘共生（分段百分比减伤）**
- **名称**：荆棘共生
- **效果描述**：HP越低，受到的伤害减免百分比越高。荆棘铠甲与血肉共生，受伤越重，防御越强。
- **触发条件**：受到伤害时自动触发，常驻被动。在伤害结算的"百分比减伤"阶段生效。
- **机制细节**：
  - HP > 75%（即HP% ∈ (75%, 100%]）：减伤20%
  - HP 50%~75%（即HP% ∈ (50%, 75%]）：减伤35%
  - HP 25%~50%（即HP% ∈ (25%, 50%]）：减伤50%
  - HP ≤ 25%（即HP% ∈ [0%, 25%]）：减伤65%
  - 区间边界规则：高端包含，低端不包含（除了最底层）。即恰好等于75%时属于"50%~75%"档，恰好等于50%时属于"25%~50%"档，恰好等于25%时属于"≤25%"档。
  - 属于百分比减伤，在固定减伤之后计算。
  - 最低伤害规则：每次伤害经过减伤后最低造成1点。
  - 视觉表现：HP降低时，少女皮肤上的荆棘藤蔓越发茂密。

**4. 主动技能：荆棘嘲讽**
- **名称**：荆棘嘲讽
- **效果描述**：强制敌方所有单体普通攻击和可被嘲讽的单体技能以自己为目标，持续1回合。
- **消耗/代价**：消耗2点行动力，CD 3回合。
- **机制细节**：
  - 嘲讽重定向范围：敌方单体普通攻击 + 明确标记为"可被嘲讽"的敌方单体技能。
  - 不受嘲讽影响：主动锦囊牌、范围/AOE技能、随机目标效果、伤害转移效果。
  - 已锁定目标后才获得嘲讽的效果不回溯。
  - 嘲讽激活时，身体周围浮现荆棘光环。

**5. 队长加成：铁壁军团**
- **名称**：铁壁军团
- **效果**：全队获得+50点临时HP（TempHP），战斗开始时生效。
- **触发条件**：荆铁担任队长时，战斗开始时全体友方角色额外获得50点临时HP。
- **机制细节**：
  - 临时HP在伤害结算中的顺序：固定减伤→百分比减伤→护盾→**临时HP**→HP。
  - 临时HP不能被治疗，战斗结束后消失。
  - 队长死亡后，已获得的临时HP不消失。
  - 后部署的英雄入场时获得临时HP。
  - 不同来源可以叠加；同一荆铁队长对同一英雄最多授予一次。后部署英雄入场时补领一次，复活、重新入场或光环刷新不会重复领取。

**6. 升星强化表**

| 星级 | 机制变化 |
|------|----------|
| 1星 | 基础减伤各档位+5%（25%/40%/55%/70%） |
| 2星 | 嘲讽CD减少1回合（CD变为2回合），胸甲纹章持续发光 |
| 3星 | 反伤减免：被克制时反伤 ×0.75（通用效果） |

**7. 同职业对比：荆铁 vs 磐姬**
- 减伤类型不同：荆铁是**百分比减伤**（越残血越硬），磐姬是**固定减伤+反震**（叠层累积）。
- 护团方式不同：荆铁通过**嘲讽**将单体攻击吸引到自己身上，磐姬通过**50%伤害分摊**让队友少受伤害。
- 队长加成不同：荆铁加**临时HP**（额外伤害吸收池），磐姬加**固定减伤**（伤害削减）。
- 视觉风格不同：荆铁是"铁甲+荆棘"的凄烈美感，越受伤越残破；磐姬是"石甲+玉石"的沉稳美感，越挨打越坚厚。

#### 05. 磐姬

**1. 角色定位说明**
- **核心定位**：前排固定减伤坦克，越挨打越厚，以伤害分摊和反震控场守护全队。
- **设计思路**：以"磐石蓄能"为核心概念——每受一击便多结一层玉石鳞片，层层堆叠既减伤又反震。区别于荆铁的"百分比减伤"，磐姬是"越战越坚"的累积式固定减伤。玉石结界技能使她能为全队分摊伤害，反震机制让攻击者付出代价。磐石每回合自然衰减，防止无限累积硬锁。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 150 | 全角色最高（与荆铁并列） |
| ATK | 9 | 先锋基准10，-10%，在±15%内 |

**3. 被动技能：磐石蓄能**
- **名称**：磐石蓄能
- **效果描述**：每次受到攻击命中（且伤害未被护盾完全吸收）时，获得1层"磐石"效果。每层磐石提供固定减伤10点和反震8点伤害。磐石层数基础最多叠加3层，每回合开始时减少1层。
- **触发条件**：受到攻击命中时获得1层磐石；每回合开始时衰减1层。常驻被动。
- **机制细节**：
  - 每层磐石：固定减伤+10，反震伤害+8。
  - 基础最大层数：3层。满层时固定减伤30点，反震24点。
  - **磐石衰减**：每回合开始时减少1层磐石（防止无限累积硬锁）。
  - **固定减伤总上限**：固定减伤总值不超过本次伤害的80%（即至少受到20%的伤害）。超过部分无效。
  - **反震上限**：反震总伤害不超过本次实际承受伤害的100%（反震不能比实际受伤还多）。超过部分无效。
  - 护盾完全吸收伤害时，不获得磐石层数，也不触发反震。
  - DOT伤害不触发磐石叠层和反震。
  - 反震造成的伤害不触发对方的反震、反伤、分摊。
  - 属于固定减伤，在百分比减伤之前计算。
  - 视觉表现：受击部位浮现翡翠色玉石鳞片，结晶点闪烁白光。

**4. 主动技能：玉石结界**
- **名称**：玉石结界
- **效果描述**：展开玉石结界，持续2回合。结界期间，所有友方受到的伤害50%由磐姬分摊承受；同时磐姬的反震效果+50%。
- **消耗/代价**：无AP消耗，CD 5回合（技能释放的唯一代价是冷却回合数）。
- **机制细节**：
  - 分摊计算：队友受到伤害时，50%由队友承受，50%转移给磐姬。
  - 分摊的伤害不能再次被分摊或转移（递归保护）。
  - 分摊到磐姬身上的伤害，正常触发磐姬的磐石叠层和反震。
  - 反震+50%：结界期间，磐姬每层磐石的反震伤害从8点变为12点（8 × 1.5 = 12）。
  - 反震上限仍然生效（不超过实际承受伤害的100%）。
  - 视觉表现：盾面石莲花泛翠光，脚下扩散翡翠色石纹结界环，友方脚下浮现淡翠色石鳞纹路。

**5. 队长加成：磐石守护**
- **名称**：磐石守护
- **效果**：全队获得固定减伤10点。
- **触发条件**：磐姬担任队长时生效，持续5个磐姬所属阵营行动回合；每次该阵营回合结束后剩余次数-1，磐姬阵亡后不再提供光环。
- **机制细节**：
  - 固定减伤10点，对所有友方角色生效，与其他固定减伤效果叠加。
  - 叠加后仍受"固定减伤不超过本次伤害80%"的总上限约束。
  - 先锋职业有队长加成符合设计准则（参考荆铁）。

**7. 同职业对比：磐姬 vs 荆铁**
- 减伤类型不同：磐姬是**固定减伤+反震**（叠层累积，每回合衰减），荆铁是**百分比减伤**（HP触发）。

- 累积限制不同：磐姬有**每回合衰减1层**和**减伤上限80%本次伤害**的硬限制，荆铁无累积限制但随HP波动。
- 基础数值不同：磐姬HP 150 / ATK 9（基准10，-10%），荆铁HP 150 / ATK 10（基准值）。

### 刺客组

#### 02. 椿偶

**1. 角色定位说明**
- **核心定位**：高攻爆发刺客，以自伤换取即时增伤，反击时额外增伤。
- **原版对应**：训练用木桩（night_blade）的美少女化重命名版，核心机制保持兼容，数值与原版一致。

- **触发条件**：进行普通攻击时自动触发，常驻被动。
- **机制细节**：
  - 仅主动攻击（玩家操作的普通攻击）时生效，反击/反震不触发此被动。

- **触发条件**：椿偶担任队长时，在反伤计算完成后增加5点伤害。
- **机制细节**：
  - 该加成属于反伤，不是额外攻击；不触发攻击命中、鸩毒、反震或再次分摊。
  - 视觉表现：背后的人偶操控线亮起红光，呈绷紧状态。

#### 06. 夜鸩

**1. 角色定位说明**
- **核心定位**：持续毒伤刺客，以鸩毒DOT削弱敌方，以剧毒穿透无视防御。
- **设计思路**：以"鸩毒叠层"为核心概念——每次攻击都在对方身上种下剧毒，毒层越多伤害越高、削弱越强。区别于椿偶的"一击爆发"，夜鸩走"持续削弱"路线。剧毒穿透技能体现毒的本质——无视一切防御，直取性命。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 75 | 刺客基准70，+7%，在±15%内 |
| ATK | 17 | 刺客基准20，-15%，刚好在边界内 |

**3. 被动技能：鸩毒缠身**
- **名称**：鸩毒缠身
- **效果描述**：攻击命中时，对目标附加1层"鸩毒"DOT实例。每层鸩毒在目标所属阵营回合开始时造成5点毒伤，并降低目标1点ATK。鸩毒基础最多叠加3层。
- **触发条件**：攻击命中时附加1层鸩毒，常驻被动。
- **机制细节**：
  - **鸩毒实例**：每层是独立实例，携带：伤害值（5点/回合）、持续时间（至战斗结束，无自然衰减）、来源。
  - 每层鸩毒：每回合5点毒伤 + 降1ATK。
  - 基础最大层数：3层。满层时每回合15点毒伤，降3ATK。
  - 鸩毒持续至战斗结束，不会自然消失（战斗中持续累积，直到达到层数上限）。
  - 毒伤结算时机：每回合开始时。
  - 毒伤属于DOT伤害，走正常伤害结算流程（固定减伤→百分比减伤→护盾→临时HP→HP）。
  - DOT伤害不视为"受到攻击"，不触发受击类被动（如磐石叠层、反震）。
  - 视觉表现：目标身上浮现幽绿色鸩毒标记（花瓣形），每回合闪烁结算。

**4. 主动技能：剧毒穿透**
- **名称**：剧毒穿透
- **效果描述**：对目标进行一次无视减伤和护盾的穿透攻击，并直接附加3层鸩毒。代价是下回合无法行动（沉寂）。
- **消耗/代价**：无AP消耗，CD 5回合；特殊代价：下回合无法行动（沉寂）。
- **机制细节**：
  - 穿透攻击：伤害 = ATK（17），无视固定减伤、百分比减伤、护盾，直接扣除临时HP和HP。
  - 附加3层鸩毒：直接将目标鸩毒层数+3（不超过最大层数上限）。
  - 沉寂（禁止行动）：使用技能后的下一个夜鸩所属阵营行动回合，夜鸩不能普通攻击、反击或释放主动技能；仍可成为目标且被动继续生效。所属玩家仍可部署英雄和使用锦囊。
  - 注意：沉寂是技能的特殊代价，不是AP消耗；"禁止行动"为独立机制类型。
  - 视觉表现：胸口夜鸩花胎记扩散发亮，毒脉纹路蔓延全身，指尖荧光穿透一切防御光效。

**5. 队长加成：无**
- **说明**：刺客职业（hero_role_2）暂无队长加成实现，与现有实现一致。
- 夜鸩作为刺客，不提供队长加成。

| 星级 | 效果 |
|------|------|

**3. 被动技能：蜃影替换**
- **名称**：蜃影替换
- **效果描述**：每回合开始时，有50%几率将对方随机一张锦囊牌替换为"蜃影"。蜃影牌打出时无效化，但仍消耗行动力。
- **触发条件**：每回合开始时判定一次，常驻被动。
- **机制细节**：
  - "每回合开始时"指的是**蜃景所属玩家的己方回合开始时**。敌方回合开始时不触发。
  - 50%触发概率，独立判定。
  - 从对方手牌中随机选择1张锦囊牌，替换为蜃影。
  - 蜃影牌外观与原牌完全一致（对方无法区分），只有打出时才会无效化。
  - 蜃影牌打出时：消耗正常行动力，但不产生任何效果，直接进入弃牌堆。
  - 视觉表现：右眼蜃之眼微闪金光，对方手牌区一张牌表面浮现蜃气波纹。

**4. 主动技能：蜃之封印**
- **名称**：蜃之封印
- **效果描述**：展示对方全部手牌，选择其中1张进行放逐。被放逐的牌进入放逐区，本局战斗中无法使用。

- **机制细节**：
  - 先展示对方全部手牌，再由玩家选择1张进行放逐。

    - 被放逐的牌进入放逐区，从手牌中移除。
    - 放逐区的牌不计入手牌上限。
    - 放逐区的牌不能被抽牌、检索、复制。
    - 战斗结束后，放逐区的牌全部还原。
  - 放逐对方的核心技能牌/锦囊牌效果最佳，可以直接废掉对方核心战术。
  - 视觉表现：右眼蜃之眼爆发沙金光芒，被封印的牌化为金色蜃气碎片消散，背景出现"蜃翼"展开剪影。

**5. 队长加成：蜃气干扰**

- **机制细节**：
  - 对方所有锦囊牌（包括被替换为蜃影的牌）打出时，均额外多消耗1点行动力。
  - 若对方行动力不足以支付增加后的消耗，则无法打出该锦囊牌。
  - 斥候职业有队长加成符合设计准则（参考影翎）。

#### 08. 曦和

**1. 角色定位说明**
- **核心定位**：进攻型祭司，以日轮灼烧造成持续伤害，以双向灼烧与敌共焚，技能附带灼烧。
- **设计思路**：以"日轮灼烧"为核心概念——日神之力用于焚毁而非削弱，越是靠近日神之力的人越会被灼烧。走进攻输出路线，区别于神无月的辅助减攻路线。双技能设计对应日相双面——日出（单向灼烧）与日蚀（双向灼烧）。灼烧被动呼应日轮永燃不息。

**2. 基础数值表**

| 属性 | 数值 | 备注 |
|------|------|------|
| HP | 80 | 低血量（与神无月并列） |
| ATK | 6 | 祭司基准5，+20%，进攻型祭司略高于基准，以DOT伤害补足输出定位 |

**3. 被动技能：炎威**
- **名称**：炎威
- **效果描述**：带有"灼烧"DOT的敌方目标在其所属阵营回合结束结算灼烧时，每层伤害+3点（炎威加成）。日神之威使火焰燃得更旺。
- **触发条件**：敌方目标的灼烧实例结算时生效，常驻被动。
- **机制细节**：
  - 结算时机：状态持有者所属阵营回合结束时（与灼烧DOT的固有结算时点一致）。
  - **炎威是对灼烧伤害的额外强化**，不是提供结算时点。灼烧DOT本身就在回合结束时结算，曦和被动使结算时每层灼烧多造成3点伤害。
  - 对所有带"灼烧"DOT的敌方角色生效，逐实例增加伤害。
  - 每层灼烧独立结算，结算后剩余回合数-1，归零则该层消失。
  - DOT伤害不视为"受到攻击"，不触发受击类被动（如磐石叠层、反震）。
  - 视觉表现：被灼烧的目标身上浮现金色火焰纹路，每回合闪烁一次造成伤害，曦和周围升腾金色炎光。

**4. 主动技能一：日轮·初灼**
- **名称**：日轮·初灼
- **效果描述**：对一名敌方目标施加1层"灼烧"DOT实例，每回合造成8点伤害，持续3回合。若目标ATK>10，额外降低其2点ATK（灼烧至力量衰退）。
- **消耗/代价**：无AP消耗，CD 5回合（与日轮·共焚共享同一冷却）。
- **机制细节**：
  - 选择目标：指定一名敌方角色。
  - **灼烧实例**：每层是独立实例，携带：伤害值（8点/回合）、持续时间（3回合）、来源。
  - 条件降攻：若目标当前ATK>10，则同时降2ATK，持续时间与灼烧同步。
  - 可叠加性：每层独立结算；同一技能在同一目标上最多保留2层，达到上限后刷新剩余时间最短的一层。
  - **双技能共享冷却**：日轮·初灼与日轮·共焚共用同一个冷却计数器。使用任意一个技能后，两个技能一起进入冷却。与2星冷却-1、队长冷却-1可叠加，最低3回合。
  - 视觉表现：神杖宝石变赤红，射出赤红光链连接目标，目标身上浮现金色火焰环绕的日轮灼烧纹。

**5. 主动技能二：日轮·共焚**
- **名称**：日轮·共焚
- **效果描述**：选择一名敌方目标，自身与目标同时被施加"双向灼烧"DOT实例——每回合各受8点灼烧伤害，持续2回合。同归于尽式的双向伤害——日神之力无差别焚毁一切。
- **消耗/代价**：无AP消耗，CD 5回合（与日轮·初灼共享同一冷却）；自身也会受到灼烧伤害（反噬）。
- **机制细节**：
  - 选择目标：指定一名敌方角色。
  - 双向灼烧：曦和自身每回合受8点灼烧伤害，目标每回合受8点灼烧伤害。持续2回合。
  - 自身灼烧伤害走正常伤害结算流程（但自身减伤对自身施加的DOT是否生效视具体规则，此处默认生效）。
  - 使用此技能后，灼烧在各自状态持有者所属阵营的下一次回合结束时首次结算；施加当刻不立即跳一次伤害。
  - **双技能共享冷却**：日轮·共焚与日轮·初灼共用同一个冷却计数器。使用任意一个技能后，两个技能一起进入冷却。
  - 视觉表现：神杖顶端日轮光线收束为暗环，自身与目标之间浮现双向赤红光链，两人脚下各出现日蚀灼烧阵纹。

**6. 队长加成：烈焰随行**
- **名称**：烈焰随行
- **效果**：友方角色使用技能时，对随机一名敌方角色施加1层灼烧DOT实例（每回合5点伤害，持续2回合）。
- **触发条件**：曦和担任队长时生效，持续5个曦和所属阵营行动回合；每次该阵营回合结束后剩余次数-1，曦和阵亡后不再触发。
- **机制细节**：
  - 触发时机：友方使用技能后。
  - 目标选择：随机一名敌方角色。
  - **灼烧实例**：伤害值5点/回合，持续2回合。
  - 多名友方在同一回合使用技能可多次触发。
  - 祭司职业有队长加成符合设计准则（参考神无月）。
  - 视觉表现：随机敌方身上浮现金色灼烧纹路。

**7. 升星强化表**

| 星级 | 效果 |
|------|------|
| 0星 | 基础形态（炎威 + 日轮·初灼 + 日轮·共焚） |
| 1星 | ATK +3 / HP +20（二选一，绝对数值突破） |
| 2星 | 技能冷却 -1回合（与队长冷却-1可叠加，最低3回合）；初灼伤害提升至每回合10点 |
| 3星 | 反伤减免：被克制时反伤 ×0.75（通用效果） |
| 4星 | ATK +5 / HP +30（二选一，绝对数值突破，取1星未选项） |
| 5星 | 共焚自身灼烧伤害减半（每回合4点），对方灼烧提升至每回合12点 |
| 6星 | 失去职业（无职业）；ATK +15，HP +35（同时增加）；被动变为"日神领域"——全场敌方灼烧伤害 +5/回合，全场友方技能附带灼烧 |

**8. 同职业对比：曦和 vs 神无月**
- 核心方向不同：曦和是**进攻灼烧+输出**（持续伤害+共焚），神无月是**辅助减攻+自愈**（削弱对方+保存自己）。
- 伤害类型不同：曦和造成**灼烧DOT持续伤害**；神无月不直接造成伤害，仅降ATK。
- 双技能设计不同：曦和双技能都是**灼烧伤害**（单烧/双烧），**双技能共享冷却**；神无月双技能都是**降ATK**（单降/双降）。
- 反噬类型不同：曦和共焚的反噬是**自身受灼烧伤害**；神无月双蚀的反噬是**自身降ATK**。
- 被动效果不同：曦和被动是**炎威强化（灼烧伤害+3点/层）**；神无月被动是**向内恢复（自愈）**。
- 视觉风格不同：曦和是"金红琥珀+日轮祭司"的灼热英气美感；神无月是"银白淡紫+月环巫女"的清冷疏离美感。
- 主题对照：曦和=日（热烈、进攻、焚毁），神无月=月（清冷、辅助、消减），二者互为镜像。
- 基础数值不同：曦和HP 80 / ATK 6（基准5，+20%，进攻型祭司），神无月HP 80 / ATK 5（基准值，全角色最低攻）。

## 第四部分：职业对位关系总览

### 先锋对位：荆铁 vs 磐姬

| 维度 | 荆铁 | 磐姬 |
|------|------|------|
| **减伤类型** | 百分比减伤（越残血越硬） | 固定减伤+反震（叠层累积，每回合衰减） |
| **核心机制** | 荆棘共生：HP分四档对应20%/35%/50%/65%减伤 | 磐石蓄能：每层固定减伤10+反震8，基础3层，每回合衰减1层 |
| **护团方式** | 嘲讽：吸引敌方单体普通攻击和可嘲讽技能到自己身上 | 玉石结界：友方伤害50%由磐姬分摊 + 反震+50% |
| **队长加成** | 全队+50临时HP（额外伤害吸收池） | 全队固定减伤10点（伤害削减） |
| **优势场景** | 面对低频高伤爆发（如刺客大招） | 面对高频低伤攻击（如多段连击） |
| **劣势场景** | 持续多段攻击将HP卡在高减伤档位前 | 单次超高伤害击穿固定减伤 + 每回合衰减导致层数不稳 |
| **硬限制** | 最低伤害1点（每次至少扣血） | 固定减伤上限为本次伤害的80%；反震上限为实际受伤的100%；每回合衰减1层 |
| **视觉主题** | 铁甲+荆棘，越伤越密，凄烈破碎之美 | 石甲+玉石，越击越厚，沉稳温润之美 |
| **设计哲学** | "以自身之残，换队友之全"——牺牲型守护 | "以自身之坚，承众人之重"——分担型守护 |

**差异化总结**：荆铁与磐姬虽然同为先锋坦克，但防御路线完全不同——荆铁走"百分比减伤+嘲讽"的单兵承伤路线，是团队的"盾牌"；磐姬走"固定减伤+分摊+反震"的团队共担路线，是团队的"城墙"。前者将伤害集中于自身，后者将伤害分散于团队。荆铁的防御随HP波动，残血时极硬；磐姬的防御随叠层增长，但有每回合衰减的硬限制，需要持续受击才能维持高层数。选择荆铁意味着相信一个人的绝对防御，选择磐姬意味着相信团队的共同承受。

### 刺客对位：椿偶 vs 夜鸩

| 维度 | 椿偶 | 夜鸩 |
|------|------|------|
| **伤害类型** | 即时爆发物理伤害 | 持续毒伤DOT+降攻 |
| **核心机制** | 主动攻击+5ATK，自伤换攻 | 攻击附带鸩毒（每层5伤+1降攻），基础3层，持续至战斗结束 |
| **主动技能** | 落椿·自损：自伤25%HP，本回合+5ATK | 剧毒穿透：无视减伤/护盾+3层鸩毒，下回合无法行动（CD 5回合，无AP消耗） |
| **代价形式** | HP（自损血量） | 时间（禁止行动/降攻） |
| **队长加成** | 全队反击+5ATK | 无（刺客职业暂无队长加成） |
| **对坦克威胁** | 中等（高ATK被高减伤稀释） | 极高（穿透无视减伤+毒伤DOT叠加） |
| **优势场景** | 快速击杀低防脆皮 | 持久战，毒层叠加后伤害爆炸 |
| **基础数值** | HP 70 / ATK 20（全角色最高攻，最低血） | HP 75 / ATK 17（基准HP70+7% / 基准ATK20-15%） |
| **视觉主题** | 瓷白人偶+黑发红瞳，诡异破碎之美 | 妖冶毒花+深紫幽绿，致命吸引之美 |
| **设计哲学** | "以自身之碎，换敌首之落"——爆发型刺客 | "以自身之毒，蚀敌骨于无形"——持续型刺客 |

**差异化总结**：椿偶与夜鸩虽然同为高攻刺客，但输出节奏完全不同——椿偶走"自伤爆发"的速杀路线，追求一击毙命，是"白刃刺客"；夜鸩走"毒伤累积"的磨血路线，追求持续削弱，是"毒系刺客"。前者的代价是鲜血，后者的代价是时间。椿偶基础ATK高达20但HP只有70，是极致的玻璃大炮；夜鸩HP 75、ATK 17，生存和输出更均衡。选择椿偶意味着追求极致的爆发快感，选择夜鸩意味着享受慢慢蚕食对手的掌控感。

### 斥候对位：影翎 vs 蜃景

| 维度 | 影翎 | 蜃景 |
|------|------|------|
| **核心方向** | 信息获取+资源增益（看穿+加速） | 幻象欺骗+资源破坏（误导+封锁） |
| **被动技能** | 每回合+1行动力（己方加速） | 50%几率替换对方锦囊为蜃影（对方浪费） |
| **主动技能** | 鸦之视野：查看并弃置对方2张手牌 | 蜃之封印：展示并放逐对方1张手牌 |
| **手牌操作** | 弃置（临时移除，可回收） | 放逐（本局移除，进入放逐区，不可回收） |
| **队长加成** | 每回合随机1张己方锦囊牌本回合费用为0（增益型） | 对方锦囊牌消耗+1行动力（削弱型） |
| **信息优势** | 我知道你有什么（信息透明） | 你不知道什么是假的（信息迷惑） |
| **优势场景** | 锦囊牌多、依赖技能的卡组 | 依赖关键牌、Combo型卡组 |
| **放逐区** | 不涉及 | 放逐区：不计入手牌上限、不能被检索/复制、战后还原 |
| **视觉主题** | 墨绿暗紫+灵鸦异色瞳，灵动元气之美 | 沙金天蓝+蜃之眼薄纱，飒爽幻影之美 |
| **设计哲学** | "看穿一切虚假，掌握真实节奏"——洞察型斥候 | "制造一切幻象，封锁敌方行动"——幻术型斥候 |
| **核心意象** | 鸦之眼——窃取真实 | 蜃之眼——编织虚假 |

**差异化总结**：影翎与蜃景虽然同为斥候，但战术逻辑完全相反——影翎是"看穿派"，通过获取真实信息和加速自方节奏来建立优势，是光明正大的情报战；蜃景是"欺骗派"，通过制造虚假幻象和放逐敌方资源来制造混乱，是虚实难辨的心理战。影翎的队长加成为己方随机1张锦囊牌费用为0（与原版风羽数据一致），重在增益自身；蜃景的队长加成为对方锦囊消耗+1，重在削弱对方。前者让你"知道得更多"，后者让你"知道的都是错的"。选择影翎意味着用信息差碾压对手，选择蜃景意味着用欺骗感玩弄对手。

### 祭司对位：神无月 vs 曦和

| 维度 | 神无月 | 曦和 |
|------|--------|------|
| **核心方向** | 辅助减攻+自愈（月蚀消减） | 持续灼烧+输出（日轮焚毁） |
| **被动技能** | 技能后自愈5%HP（向内恢复） | 炎威（灼烧伤害+3点/层，强化灼烧DOT） |

| **队长加成** | 全队技能冷却-1（循环加速） | 友方使用技能时随机敌方灼烧（附加伤害） |
| **团队定位** | 纯辅助（削弱对方+保护队友） | 进攻型辅助（持续伤害+削弱） |

**差异化总结**：神无月与曦和虽然同为祭司双技能角色，但功能定位完全相反——神无月是"月之祭司"，走纯辅助路线，以月蚀之力削弱对方攻击，以自愈维持生存，是团队的"镇定剂"；曦和是"日之祭司"，走进攻型辅助路线，以日轮之力持续灼烧对方，以共焚换取爆发伤害，是团队的"催化剂"。神无月ATK为5（全角色最低），曦和ATK为6并以DOT补足输出。前者让敌人"打不动"，后者让敌人"活不长"。二者互为日月对照——一个清冷一个热烈，一个内敛一个外放，一个守护一个焚毁。选择神无月意味着稳扎稳打的消耗战，选择曦和意味着轰轰烈烈的速决战。
